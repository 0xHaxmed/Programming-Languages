## 🎯 نظرة عامة على المشروع
في هذا المشروع التطبيقي للمستوى الأول، ستقوم بفحص وتخصيص **بطاقة تعريفية لمطور (Developer Portfolio Card)** مبنية وفق أفضل معايير HTML5 الدلالية وقواعد لغة CSS الدفاعية.

### المزايا الهندسية المحققة في المشروع:
- **صفر مكتبات خارجية:** كود خام 100% بلغة HTML5 و CSS3 المعيارية.
- **تطبيق نموذج الصندوق الدفاعي:** ضبط شامل لـ `box-sizing: border-box` لضمان ثبات أبعاد العناصر عند إضافة الحشو والإطارات.
- **خطوط قياسية ميسرة للوصول:** استخدام وحدة `rem` لاحترام إعدادات تكبير الخط في متصفحات المستخدمين.
- **تأمين الروابط الخارجية:** حماية الروابط من ثغرات Reverse Tabnabbing عبر `target="_blank" rel="noopener noreferrer"`.
- **استقرار العرض البصري:** تحديد أبعاد صريحة `width` و `height` للصورة لمنع اهتزاز الصفحة عند التحميل (CLS).

## 🚀 كيفية تشغيل ومعاينة المشروع محلياً

1. افتح ملف `index.html` مباشرة في متصفحك:
   - في نظام ويندوز: انقر مرتين على الملف، أو نفذ الأمر:
     ```powershell
     Start-Process chrome.exe "E:\Programming Languages\02-HTML-CSS\Level-1-Basic\Final-Project\index.html"
     ```
   - أو شغّل سيرفر محلياً باستخدام بايثون:
     ```bash
     python -m http.server 8080
     ```
2. افتح **أدوات مطوري الويب في المتصفح** (`F12` أو `Ctrl+Shift+I`):
   - افتح تبويب **Elements**.
   - حدد عنصر `.profile-card` ثم انتقل إلى تبويب **Computed**.
   - شاهد مخطط نموذج الصندوق (Box Model) ولاحظ كيف تُحسب قيم `margin` و `border` و `padding` بدقة متناهية.

## 🏆 تحدي التخصيص للمتدرب

1. غيّر الاسم، المسمى الوظيفي، النبذة، والمهارات لتعكس بياناتك وخبراتك الحقيقية.
2. عدّل تدرج ألوان ترويسة البطاقة عبر نظام HSL.
3. أضف زراً ثالثاً في تذييل البطاقة يوجه إلى مدونتك أو موقعك الشخصي مع التأكد من إضافة `rel="noopener noreferrer"`.
