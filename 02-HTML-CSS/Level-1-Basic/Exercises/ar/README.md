## 🎯 الهدف
ترسيخ المفاهيم الجوهرية للغة HTML الدلالية، أمان الروابط، حجز أبعاد الوسائط، الجداول المتاحة لقارئات الشاشة، ونموذج الصندوق (Box Model) من خلال 5 تدريبات عملية محددة.

---

## 🏋️ التمرين 1: إعادة هيكلة كود الـ "Div Soup" إلى وسوم دلالية

### نص المشكلة:
قام مطور قديم بكتابة الهيكل التالي باستخدام وسوم `<div>` فقط دون أي معنى دلالي:
```html
<div class="header">
    <div class="logo">DevSecOps</div>
</div>
<div class="title">Web Security Foundations</div>
<div class="content">
    <div class="paragraph">Cross-Site Scripting occurs when untrusted input is executed.</div>
</div>
<div class="footer">
    <div class="copyright">&copy; 2026 DevSecOps</div>
</div>
```

### المطلوب منك:
أعد كتابة هذا الهيكل باستخدام وسوم HTML5 الدلالية: `<header>`, `<nav>`, `<h1>`, `<main>`, `<p>`, و `<footer>`. واشرح كيف يفيد ذلك برمجيات قارئات الشاشة ومحركات البحث.

---

## 🏋️ التمرين 2: رابط خارجي آمن وبطاقة وسائط مقاومة للاهتزاز

### نص المشكلة:
ابنِ بطاقة تعريفية لمطور تحتوي على:
1. صورة شخصية (`width="120"`, `height="120"`, نص بديل دلالي `alt`, وخاصية `loading="lazy"`).
2. نبذة تعريفية تضم كلمات مشدد عليها بـ `<strong>` ومقتطفات برمجية بـ `<code>`.
3. رابط خارجي لصفحة حسابه على GitHub يفتح في تبويب جديد.

### الشرط الأمني الإلزامي:
يجب أن يحمي الرابط المتصفح من ثغرة Reverse Tabnabbing عبر إدراج `target="_blank"` مع `rel="noopener noreferrer"`.

---

## 🏋️ التمرين 3: جدول تقرير أمني مطابق لمعايير الوصول (Accessibility)

### نص المشكلة:
أنشئ جدول HTML يوثق نتائج فحص أمني لثلاث ثغرات:
- الثغرة الأولى: DOM XSS | خطورة عالية | تم الإصلاح
- الثغرة الثانية: Missing CSRF Token | خطورة متوسطة | قيد المعالجة
- الثغرة الثالثة: Information Disclosure | خطورة منخفضة | مقبولة المخاطر

### متطلبات إمكانية الوصول:
- يجب أن يحتوي الجدول على عنوان توضيحي `<caption>`.
- تقسيم الجدول إلى `<thead>`, `<tbody>`, و `<tfoot>`.
- تخصيص `scope="col"` لرؤوس الأعمدة و `scope="row"` لأسماء الثغرات.
- استخدام `colspan` في سطر التذييل لدمج الخلايا وحساب إجمالي الثغرات.

## 🏋️ التمرين 4: الحساب الهندسي الدقيق لنموذج الصندوق (Box Model)

### نص المشكلة:
لديك مواصفات تصميمية لبطاقة محددة:
- العرض الإجمالي على الشاشة: **360px**
- الحشو الداخلي يميناً ويساراً: **24px لكل جانب**
- إطار الحدود يميناً ويساراً: **2px solid #cbd5e1**
- لون الخلفية: `#f8fafc`

### المطلوب منك:
اكتب قواعد CSS لفئة `.spec-card`:
1. استخدم قاعدة `box-sizing: border-box`.
2. عاين العنصر في أدوات المتصفح (Inspect -> Elements -> Computed).
3. تأكد من أن العرض النهائي على الشاشة هو 360px تماماً دون أي خلل في الأبعاد.

---

## 🏋️ التمرين 5: شريط تنقل أفقي متجاوب عبر CSS الخالص

### نص المشكلة:
حوّل قائمة HTML رأسية عادية إلى شريط تنقل أفقي أنيق ومتاح:
```html
<nav class="site-nav">
    <ul>
        <li><a href="#home">الرئيسية</a></li>
        <li><a href="#docs">التوثيق</a></li>
        <li><a href="#tools">الأدوات</a></li>
        <li><a href="#security">الأمان</a></li>
    </ul>
</nav>
```

### متطلبات التنسيق:
1. إزالة النقاط الافتراضية للقائمة (`list-style: none`) وتصفير الهوامش.
2. استخدام `display: inline-block` للروابط أو عناصر القائمة لتصطف أفقياً جنباً إلى جنب.
3. إضافة حشو داخلي مريح ولون خلفية تفاعلي عند مرور الفأرة (`:hover`).
4. إضافة إطار تركيز واضح (`:focus-visible`) للتنقل عبر لوحة المفاتيح.
