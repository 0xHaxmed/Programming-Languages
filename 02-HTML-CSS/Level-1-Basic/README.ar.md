## 🎯 الهدف التعليمي للمستوى الأول

- **الهدف:** إتقان الهيكل الأساسي لمستندات HTML، والوسوم الدلالية الشائعة، وقواعد لغة CSS الأساسية.
- **التركيز:** كود نظيف، معايير إتاحة الويب الأولية، ربط CSS، الألوان والوحدات، وإتقان فهم **صندوق العنصر (The Box Model)**.
