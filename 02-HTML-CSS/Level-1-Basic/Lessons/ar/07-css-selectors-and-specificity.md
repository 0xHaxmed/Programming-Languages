# 07 - محددات CSS، التعاقب وحساب الأولوية (Specificity)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/07-css-selectors-and-specificity.md) | [العربية 🇸🇦](./07-css-selectors-and-specificity.md)

## 📌 1. المحددات الأساسية والروابط العلائقية (Combinators)

تحدد محددات CSS عناصر الـ DOM المستهدفة بناءً على اسم الوسم، الفئة (Class)، المعرف (ID)، العلاقات الشجرية، أو الخصائص:

### أ. المحددات الأساسية:
```css
* { /* المحدد الشامل: يطابق كل عنصر في الصفحة */ }
p { /* محدد النوع: يطابق كافة فقرات <p> */ }
.btn { /* محدد الفئة: يطابق أي عنصر يحمل class="btn" */ }
#header { /* محدد المعرف: يطابق العنصر الفريد الذي يحمل id="header" */ }
```

### ب. محددات العلاقات الشجرية (Combinators):
```css
/* السليل (Descendant): أي رابط داخل .nav على أي عمق */
.nav a { color: #0284c7; }

/* الابن المباشر (Direct Child): فقط عناصر <li> التابعة مباشرة لـ <ul> */
ul > li { list-style: square; }

/* الشقيق المجاور المباشر (Adjacent Sibling): أول فقرة تأتي مباشرة بعد <h2> */
h2 + p { font-size: 1.2rem; }

/* الأشقاء العامون (General Sibling): كل الفقرات التالية لـ <h2> في نفس المستوى */
h2 ~ p { line-height: 1.6; }
```

## 🔍 2. محددات الخصائص (Attribute Selectors - أساس أمان CSS)

تتيح لك استهداف العناصر وفق قيم خصائصها المكتوبة في HTML:

```css
/* مطابقة تامة: حقل الإدخال بنوع كلمة مرور */
input[type="password"] { border-color: #ef4444; }

/* مطابقة البادئة (^=): الروابط التي تبدأ بـ https:// */
a[href^="https://"] { text-decoration: underline; }

/* مطابقة اللاحقة ($=): الروابط التي تنتهي بملف pdf. */
a[href$=".pdf"] { color: #dc2626; }

/* مطابقة احتواء النص (*=): الفئات التي تتضمن كلمة admin */
div[class*="admin"] { background: #fef2f2; }
```

> 🛡️ **إضاءة أمنية استباقية:** في المستوى الثالث، ستتعلم كيف يستغل المخترقون محددات البادئة (`input[value^="a"]`) في هجمات سرقة رموز التحقق (CSRF Tokens) وكلمات المرور حرفاً بحرف عبر CSS الخالص ودون الحاجة لأي كود جافا سكريبت!

## 🎭 3. الفئات والعناصر الزائفة (Pseudo-classes & Pseudo-elements)

- **الفئات الزائفة (`:state`):** تستهدف العنصر عند تغير حالته التفاعلية:
  - `:hover` — مرور مؤشر الفأرة فوق العنصر.
  - `:focus` — حصول العنصر على التركيز عبر لوحة المفاتيح (حاسم لإمكانية الوصول a11y).
  - `:active` — لحظة النقر الفعلي على العنصر.
  - `:disabled` — عندما يكون حقل الإدخال أو الزر معطلاً.
  - `:nth-child(2n)` — استهداف العناصر الزوجية في القوائم.

- **العناصر الزائفة (`::part`):** تنسيق أجزاء فرعية أو حقن محتوى زخرفي:
  - `::before` و `::after` — إدراج محتوى شكلي قبل أو بعد محتوى العنصر عبر `content: ""`.
  - `::placeholder` — تنسيق النص الإرشادي الداخلي لحقول الإدخال.

```css
.button {
    background-color: #0284c7;
    transition: background 0.2s ease;
}

.button:hover {
    background-color: #0369a1;
}

.button:focus-visible {
    outline: 2px solid #38bdf8;
    outline-offset: 2px;
}
```

## ⚖️ 4. معادلة وقواعد حساب الأولوية والتعاقب (Specificity)

عند وجود قاعدتين متعارضتين تنطبقان على نفس العنصر، يحسب المتصفح **نقاط الأولوية (Specificity Score)**:

```
 ┌─────────────┬────────────────┬──────────────────────┬───────────────────────┐
 │ المضمن (A)  │ المعرفات (B)   │ الفئات والخصائص      │ العناصر والوسوم       │
 │             │                │ والحالات الزائفة (C) │ والعناصر الزائفة (D)   │
 ├─────────────┼────────────────┼──────────────────────┼───────────────────────┤
 │ style="..." │ #main-nav      │ .btn, [type="text"], │ p, div, h1,           │
 │             │                │ :hover               │ ::before              │
 └─────────────┴────────────────┴──────────────────────┴───────────────────────┘
```

### الترتيب الهرمي للأوزان:
1. التنسيق المضمن في HTML: **(1, 0, 0, 0)**
2. المعرفات (`#id`): **(0, 1, 0, 0)**
3. الفئات والخصائص (`.class`, `[attr]`, `:hover`): **(0, 0, 1, 0)**
4. الوسوم والعناصر الزائفة (`p`, `::after`): **(0, 0, 0, 1)**

### مثال حسابي تطبيقي:
- `nav ul li a` = 4 عناصر = **(0, 0, 0, 4)**
- `nav ul li a.active` = فئة واحدة + 4 عناصر = **(0, 0, 1, 4)** (يفوز!)
- `#main-nav a.active` = معرف واحد + فئة واحدة + عنصر واحد = **(0, 1, 1, 1)** (يسحق ما قبله!)

> ⚠️ **خطر استخدام `!important`:** تجنب استخدام `!important` في الشيفرات اليومية. إنه يعطل منطق التعاقب ويجعل تعديل الأكواد مستقبلاً كابوساً. اعتمد دائماً على تنظيم الفئات بهندسة واضحة (مثل منهجية BEM).

## 🎯 ملخص وتحدي الدرس

- المحددات العلائقية تشرح العلاقات في شجرة الـ DOM (`>`, `+`, `~`).
- محددات الخصائص تتيح استهدافاً ديناميكياً ذكياً للقيم.
- أوزان الأولوية الأربعة تحسم دائماً أي قاعدة تنسيق ستطبق في النهاية.

**تحدي الدرس:** اكتب صفحة تحوي قائمة روابط، واجعل الروابط الآمنة `https://` خضراء، وروابط ملفات الـ `pdf.` حمراء، مع تغيير لون الخلفية عند `:hover` و`:focus`.
