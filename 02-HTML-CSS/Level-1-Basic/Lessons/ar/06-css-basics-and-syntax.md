# 06 - أساسيات وقواعد لغة CSS

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/06-css-basics-and-syntax.md) | [العربية 🇸🇦](./06-css-basics-and-syntax.md)

---

## 📌 1. ما هي لغة CSS؟

**CSS (Cascading Style Sheets - صفحات التنسيق الانسيابية)** هي اللغة المسؤولة عن تنسيق وعرض مستندات HTML على الشاشات أو عند الطباعة. بينما تتولى HTML تحديد **الهيكل والمعنى الدلالي**، تتحكم CSS في **الألوان، الخطوط، التخطيط العام، والتجاوب مع الشاشات**.

---

## 🏗️ 2. تشريح قاعدة CSS (CSS Rule Anatomy)

تتألف قاعدة CSS من **المحدد (Selector)** و**كتلة الإعلانات (Declaration Block)**:

```css
selector {
    property: value;
    property: value;
}
```

```
     المحدد (Selector)       كتلة الإعلانات (Declaration Block)
   ┌──────────┐            ┌─────────────────────────┐
    h1.heading  {           color: #0284c7;           }
                            └────────────┘
                              الإعلان (Declaration)
                            ├───┤  ├─────┤
                            الخاصية  القيمة
```

### المكونات:
- **المحدد (Selector):** يشير إلى عناصر HTML المراد تنسيقها (مثل `h1.heading`).
- **الخاصية (Property):** السمة البصرية التي تعدلها (مثل `color`, `font-size`, `margin`).
- **القيمة (Value):** الإعداد المطبق على تلك الخاصية (مثل `#0284c7`, `1.5rem`).
- **الفاصلة المنقوطة (`;`):** يجب أن تنهي كل سطر إعلان داخل القاعدة.

## 🔌 3. الطرق الثلاث لتطبيق CSS على HTML

### أ. ملف التنسيق الخارجي (External Stylesheet - المعيار المعتمد):
يتم ربطه داخل وسوم `<head>` عبر عنصر `<link>`:
```html
<head>
    <link rel="stylesheet" href="styles.css">
</head>
```
- **المزايا:** فصل كامل للمهام، دعم التخزين المؤقت في المتصفح (Browser Caching)، وسهولة الصيانة.
- **الأمان:** متوافق تماماً مع سياسات أمان المحتوى الصارمة (CSP: `style-src 'self'`).

### ب. وسوم التنسيق الداخلية (Internal `<style>`):
توضع مباشرة داخل `<head>`:
```html
<head>
    <style>
        body { background-color: #f8fafc; }
    </style>
</head>
```
- **الاستخدام:** مشاريع العرض السريع المكونة من ملف واحد.

### ج. التنسيق المضمن المباشر (Inline Styles - نمط سيئ):
يُكتب كخاصية داخل وسم العنصر مباشرة:
```html
<p style="color: red; font-size: 14px;">تحذير</p>
```
- **لماذا يجب تجنبه؟** صعوبة بالغة في الصيانة والتعديل، انعدام إمكانية إعادة الاستخدام، ويتم **حظره تلقائياً بواسطة سياسات الأمان القياسية CSP** لحماية الموقع من هجمات التعديل غير المصرح به.

## 🧹 4. إعدادات المتصفح الافتراضية وتصفير التنسيق (CSS Reset)

تأتي المتصفحات (كروم، فايرفوكس، سفاري) مع تنسيقات افتراضية مسبقة تسمى **User-Agent Stylesheet**. وتختلف هذه الهوامش والمسافات قليلاً بين متصفح وآخر.

لضمان ظهور موقعك بشكل متطابق 100% في كافة المتصفحات، يعتمد مهندسو الويب كود تصفير مبسط (Minimal CSS Reset):

```css
/* تصفير الهوامش وتوحيد طريقة حساب الأبعاد */
*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}
```

## 🎯 ملخص وتحدي الدرس

- لغة CSS مسؤولة عن الجماليات والشكل، وHTML عن البنية والمعنى.
- تتكون قاعدة التنسيق من محدد، خاصية، وقيمة.
- اعتمد دائماً على الملفات الخارجية `.css`.
- استخدم كود تصفير CSS لتوحيد الهوامش وسلوك المتصفحات.

**تحدي الدرس:** أنشئ ملف `index.html` وملف `styles.css` منفصلاً، اربطهما عبر `<link>`، وأعطِ خلفية للصفحة مع تنسيق عنوان `<h1>` بلون ونوع خط أنيق.
