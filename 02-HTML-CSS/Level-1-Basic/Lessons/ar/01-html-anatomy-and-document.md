# 01 - تشريح لغة HTML وهيكل المستند

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/01-html-anatomy-and-document.md) | [العربية 🇸🇦](./01-html-anatomy-and-document.md)

---

## 📌 1. ما هي لغة HTML؟

**HTML (HyperText Markup Language - لغة ترميز النص الفائق)** هي المعيار القياسي لبناء وهيكلة صفحات ومستندات الويب. إنها **ليست** لغة برمجة؛ بل هي لغة ترميزية توجيهية (Declarative Markup) تخبر محرك المتصفح بكيفية تجميع وتنسيق وعرض النصوص، الصور، النماذج، والوسائط المتعددة.

---

## 🏗️ 2. تشريح عنصر HTML (Element Anatomy)

يتكون عنصر HTML النموذجي من وسم بداية (Opening Tag)، خصائص اختيارية (Attributes)، المحتوى النصي، ووسم نهاية (Closing Tag):

```
    وسم البداية          المحتوى            وسم الإغلاق
      ┌──────┐      ┌─────────────┐       ┌───────┐
      <p class="intro">مرحباً بكم في الويب</p>
         └───────────┘
          الخاصية (Attribute)
```

### قواعد أساسية:
1. **الخصائص (`name="value"`):** توفر بيانات وصفية أو إعدادات للعنصر (مثل: `class`, `id`, `href`, `src`).
2. **العناصر الفارغة / ذاتية الإغلاق (Void Elements):** عناصر لا تحتوي على نص داخلي ولا تحتاج وسم إغلاق منفصل (مثل: `<img />`, `<input />`, `<br />`, `<meta />`).

---

## 📄 3. الهيكل القياسي الموحد لمستند HTML5

كل صفحة ويب حديثة تبدأ بهذا الهيكل البرمجي القياسي:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>هيكل مستند HTML5 القياسي</title>
</head>
<body>
    <h1>مرحباً بك في عالم الويب الحديث!</h1>
    <p>هذا أول مستند HTML5 قياسي نقوم ببنائه.</p>
</body>
</html>
```

### تفكيك مكونات الهيكل:
- **`<!DOCTYPE html>`:** يُلزم محرك المتصفح بالعرض وفق **الوضع القياسي (Standard Mode)** وتجنب وضع التوافق القديم (Quirks Mode).
- **`<html lang="ar" dir="rtl">`:** الحاوية الجذرية لكامل الصفحة. خاصية `lang` حاسمة لقارئات الشاشة ومحركات البحث، وخاصية `dir="rtl"` تضبط اتجاه الكتابة من اليمين إلى اليسار للغة العربية.
- **`<head>`:** مستودع البيانات الوصفية (Metadata)، العناوين، الروابط بملفات التنسيق، وتشفير المحارف. لا يُعرض أي شيء داخله في مساحة الصفحة المرئية مباشرة.
- **`<meta charset="UTF-8">`:** يفرض تشفير المحارف العالمي UTF-8 لعرض النصوص العربية والرموز التعبيرية (Emojis) دون تشوه.
- **`<meta name="viewport" content="width=device-width, initial-scale=1.0">`:** سطر أمان التصميم المتجاوب (Responsive Design)، يضمن توافق حجم العرض في الهواتف مع شاشاتها الحقيقية.
- **`<body>`:** يحتوي على كافة العناصر المرئية والتفاعلية التي يشاهدها المستخدم ويتفاعل معها.

---

## 🎯 ملخص وتحدي الدرس

- لغة HTML تبني الهيكل الدلالي للموقع.
- الخصائص (Attributes) تتحكم بسلوك العناصر ومظهرها.
- لا تنشئ صفحة ويب دون `DOCTYPE`, `lang`, `UTF-8`, ووسم `viewport`.

**تحدي الدرس:** أنشئ ملفاً باسم `index.html` على جهازك، الصق الهيكل أعلاه، غيّر العنوان إلى اسمك، وافتحه في المتصفح!
