# 03 - الروابط التشعبية وتأمين وسوم Anchor

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/03-links-and-anchors.md) | [العربية 🇸🇦](./03-links-and-anchors.md)

---

## 📌 1. عنصر الرابط التشعبي (`<a>`)

الروابط التشعبية هي جوهر شبكة الويب العالمية. يربط وسم `<a>` (Anchor) المستند الحالي بصفحات أخرى، أو بأقسام محددة داخل نفس الصفحة، أو ببروتوكولات خارجية.

```html
<a href="https://developer.mozilla.org">توثيق مطوري موزيلا MDN</a>
```

### الخصائص الأساسية:
- **`href` (Hypertext Reference):** المسار أو الرابط الموجه إليه.
- **`target`:** يحدد مكان فتح الصفحة المستهدفة (مثلاً: `_self` الافتراضي في نفس التبويب، أو `_blank` في تبويب جديد).
- **`download`:** يطلب من المتصفح تحميل الملف المستهدف بدلاً من استعراضه.

---

## 🌐 2. أنواع وجهات الروابط

### أ. الروابط المطلقة مقابل النسبية (Absolute vs Relative):
```html
<!-- رابط مطلق (نطاق خارجي كامل) -->
<a href="https://example.com/docs">التوثيق الخارجي</a>

<!-- رابط نسبي (صفحات فرعية في نفس المشروع) -->
<a href="./about.html">من نحن</a>
<a href="../dashboard/settings.html">إعدادات الحساب</a>
```

### ب. الروابط الداخلية للأقسام (Jump Links):
```html
<!-- زر الانتقال السريع -->
<a href="#security-section">انتقل إلى تفاصيل الأمان</a>

<!-- القسم المستهدف بالمعرف id -->
<h2 id="security-section">سياسة الأمان والامتثال</h2>
```

### ج. مخططات البروتوكولات الخاصة (`mailto:` و `tel:`):
```html
<a href="mailto:security@example.com">مراسلة فريق الأمان</a>
<a href="tel:+18005550199">الاتصال بالدعم الفني</a>
```

## 🛡️ 3. تحذير أمني خطير: ثغرة Tabnabbing مع `target="_blank"`

عند فتح رابط في تبويب جديد باستخدام `target="_blank"`، يمنح المتصفح النافذة الجديدة وصولاً برمجياً إلى الصفحة الأصلية عبر كائن `window.opener`:

```
   الصفحة الأصلية (الضحية) ───[ target="_blank" ]───► موقع المهاجم
                                                              │
   إعادة توجيه صفحة الضحية لصفحة تصيد ◄── window.opener.location
```

يستطيع موقع المهاجم تنفيذ الكود التالي:
```javascript
window.opener.location = "https://phishing-site.com/fake-login";
```
عندما يعود المستخدم للتبويب الأصلي، يجد صفحة تسجيل دخول مزيفة تطلب منه كلمة المرور مجدداً فيقع ضحية للتصيد!

### 🔒 الحماية الصارمة: `rel="noopener noreferrer"`
```html
<!-- رابط آمن: يقطع الاتصال بنافذة المتصفح الأصلية ويمنع تسريب الـ Referrer -->
<a href="https://untrusted-external-site.com" target="_blank" rel="noopener noreferrer">
    زيارة الموقع الخارجي
</a>
```
- **`noopener`:** يضبط كائن `window.opener` إلى `null` لمنع التحكم بالصفحة السابقة.
- **`noreferrer`:** يمنع المتصفح من إرسال عنوان صفحتك الحالية في ترويسة الطلب `Referer`.

---

## ⚠️ 4. تحذير أمني: تجنب روابط `javascript:` تماماً

إياك واستخدام `href="javascript:..."` لتنفيذ أكواد أو تشغيل دوال:
```html
<!-- خطير للغاية: إذا احتوى الرابط على مدخلات مستخدم، يسبب ثغرة XSS مباشرة -->
<a href="javascript:alert(1)">اضغط هنا</a>

<!-- الأسلوب الآمن الصحيح: استخدام وسم <button> مع كود جافا سكريبت منفصل -->
<button type="button" class="action-btn">إجراء آمن</button>
```

---

## 🎯 ملخص وتحدي الدرس

- اكتب نصوص روابط دلالية واضحة (تجنب عبارات مبهمة مثل "اضغط هنا").
- أي رابط خارجي يستخدم `target="_blank"` **يجب أن يرافقه `rel="noopener noreferrer"`**.
- استخدم وسم `<button>` للإجراءات التفاعلية ووسم `<a>` للتنقل بين الصفحات.

**تحدي الدرس:** أنشئ صفحة HTML تحتوي على رابط ينتقل لأسفل الصفحة (Jump Link)، ورابط خارجي آمن ومحمي بـ `rel="noopener noreferrer"`.
