# 02 - العناوين والفقرات ودلالات النصوص

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/02-text-headings-and-paragraphs.md) | [العربية 🇸🇦](./02-text-headings-and-paragraphs.md)

## 📌 1. التدرج الهرمي للعناوين (`<h1>` إلى `<h6>`)

توفر لغة HTML ستة مستويات من العناوين لتنظيم المستند. العناوين ليست مجرد وسيلة لتكبير حجم الخط، بل هي الهيكل الفعلي لفهرس ومحتوى الصفحة:

```html
<h1>عنوان المستند الرئيسي (عنصر واحد فقط في الصفحة)</h1>
<h2>عنوان قسم رئيسي</h2>
<h3>عنوان فرعي تفرعي</h3>
<h4>عنوان مكون داخلي</h4>
<h5>مجموعة فرعية صغيرة</h5>
<h6>تفصيل دقيق</h6>
```

### أفضل الممارسات وقواعد إمكانية الوصول (Accessibility):
- **لا تتخطَّ مستويات العناوين:** (مثلاً: القفز من `<h2>` مباشرة إلى `<h4>`). قارئات الشاشة للمكفوفين تعتمد على الترتيب المتسلسل للتنقل.
- **قاعدة الـ `<h1>` الواحد:** خصص عنوان `<h1>` وحيداً في الصفحة يعبر عن موضوعها الأساسي (حاسم جداً للـ SEO ومحركات البحث).
- **التنسيق عبر CSS وليس الوسوم:** لا تستخدم `<h3>` لمجرد رغبتك في تصغير حجم النص؛ استخدم CSS `font-size` للتحكم في المظهر.

## 📝 2. الفقرات وفواصل الأسطر

- **الفقرة `<p>`:** تمثل كتلة نصية قائمة بذاتها، ويضيف المتصفح تلقائياً هوامش قبلها وبعدها.
- **فاصل السطر `<br>`:** يجبر المتصفح على كسر السطر داخل نفس الفقرة دون إنشاء فقرة جديدة.
- **الخط الفاصل الأفقي `<hr>`:** يعبر عن انتقال دلالي بين فكرتين أو موضوعين.

```html
<p>
    لغة HTML تمثل العمود الفقري لكافة مواقع الويب.<br>
    فهي المسؤولة عن بناء وهيكلة المحتوى.
</p>
<hr>
<p>هنا يبدأ موضوع وفكرة جديدة تماماً.</p>
```

## 🏷️ 3. وسوم التنسيق الدلالية (Semantic Formatting)

تفصل HTML الحديثة بين **المظهر الشكلي** و**المعنى الدلالي**:

| الوسم | الغرض الدلالي | المظهر الافتراضي | متى نستخدمه؟ |
| :--- | :--- | :--- | :--- |
| `<strong>` | أهمية قصوى، خطورة، أو تحذير عاجل | **عريض (Bold)** | التحذيرات، المصطلحات الحرجة |
| `<b>` | إبراز بصري دون إضافة أهمية دلالية | **عريض (Bold)** | الكلمات المفتاحية وأسماء المنتجات |
| `<em>` | تأكيد نبرة الصوت في القراءة | *مائل (Italics)* | الكلمات المشدد عليها في الجمل |
| `<i>` | مصطلح تقني أو فكرة جانبية | *مائل (Italics)* | المصطلحات اللاتينية، التقنية |
| `<mark>` | نص مظلل كمرجع للقارئ | خلفية صفراء | تمييز نتائج البحث |
| `<code>` | كتابة مقتطفات برمجية | خط أحادي العرض (Monospace) | أسماء الدوال، المتغيرات |
| `<blockquote>` | اقتباس نصي خارجي طويل | إزاحة داخلية | الاقتباسات من مراجع خارجية عبر `cite` |

### مثال عملي:
```html
<p>
    <strong>تحذير أمني:</strong> تحقق دائماً من مدخلات المستخدم واستخدم دالة <code>sanitizeInput</code>.
</p>
<blockquote cite="https://www.w3.org">
    "قوة الويب تكمن في كونه متاحاً للجميع عالمياً."
</blockquote>
```

---

## 🎯 ملخص وتحدي الدرس

- استخدم العناوين `<h1>` إلى `<h6>` لبناء فهرس منطقي، وليس لتغيير حجم الخط.
- فرّق دائماً بين الوسوم ذات المعنى الدلالي (`<strong>`) ومجرد الشكل (`<b>`).
- احرص على استخدام `<code>` و`<mark>` لتوثيق المفاهيم بوضوح.

**تحدي الدرس:** اكتب صفحة سيرة ذاتية مصغرة تضم `<h1>`، قسمين `<h2>`، فقرات تحتوي على `<strong>` و`<em>`، ومقتطف برمجي باستخدام `<code>`.
