# 08 - نموذج الصندوق في CSS وحساب الأبعاد (The Box Model)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/08-the-box-model.md) | [العربية 🇸🇦](./08-the-box-model.md)

---

## 📌 1. كل شيء في CSS عبارة عن صندوق

في نظام تصميم متصفحات الويب، يتعامل المتصفح مع كل عنصر HTML على أنه صندوق مستطيل الشكل. فهم كيفية حساب هذا الصندوق لأبعاده ومساحاته هو حجر الزاوية الأهم في هندسة الويب وتصميم الواجهات.

---

## 📦 2. الطبقات الأربع لنموذج الصندوق (The 4 Layers)

من الداخل إلى الخارج، يتكون أي صندوق من 4 طبقات متداخلة:

```
┌────────────────────────────────────────────────────────┐
│               الهامش الخارجي (MARGIN)                  │
│   ┌────────────────────────────────────────────────┐   │
│   │                 الإطار (BORDER)                │   │
│   │   ┌────────────────────────────────────────┐   │   │
│   │   │        الحشو الداخلي (PADDING)         │   │   │
│   │   │   ┌────────────────────────────────┐   │   │   │
│   │   │   │       المحتوى (CONTENT)        │   │   │   │
│   │   │   │    (النص، الصورة، العنصر)      │   │   │   │
│   │   │   └────────────────────────────────┘   │   │   │
│   │   └────────────────────────────────────────┘   │   │
│   └────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

1. **المحتوى (Content):** النص الفعلي، أو الصورة، أو العناصر الفرعية (`width`, `height`).
2. **الحشو الداخلي (Padding):** مسافة بيضاء شفافة تفصل المحتوى عن الإطار الداخلي (`padding: 16px`). ألوان الخلفيات تملأ منطقة الـ Padding.
3. **الإطار (Border):** الحد المحيط الذي يلف المحتوى والحشو الداخلي (`border: 1px solid #cbd5e1`).
4. **الهامش الخارجي (Margin):** مساحة فارغة شفافة خارج الإطار، تفصل العنصر عن العناصر المجاورة له (`margin: 24px auto`).

---

## 📐 3. الفرق الجوهري: `content-box` مقابل `border-box`

افتراضياً في المعايير القديمة لـ CSS، يستخدم المتصفح `box-sizing: content-box`:

### المشكلة في النموذج القديم (`content-box`):
إذا حددت الكود التالي:
```css
.card {
    box-sizing: content-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}
```
**العرض النهائي الحقيقي على الشاشة:**  
`300px (المحتوى) + 40px (الحشو يميناً ويساراً) + 10px (الإطار يميناً ويساراً) = 350px!`  
العنصر تمدد فجأة بمقدار 50 بكسل إضافية ودمر تناسق التخطيط!

### الحل الهندسي الحديث (`border-box`):
```css
*, *::before, *::after {
    box-sizing: border-box;
}

.card {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}
```
**العرض النهائي الحقيقي على الشاشة:**  
`300px تماماً دون أي زيادة!`  
يقوم المتصفح تلقائياً بتقليص مساحة المحتوى الداخلي (`250px`) ليمتص الحشو والإطار ضمن العرض المطلوب. الحسابات هنا دقيقة ومتوقعة 100%.

---

## 🧲 4. ظاهرة انهماك الهوامش (Margin Collapse)

عندما يجلس عنصران كتليان (Block elements) عمودياً فوق بعضهما، لا تجمع هوامشهما الرأسية، بل "تنهار" وتندمج في هامش واحد يساوي القيمة الأكبر بينهما:

```
  عنصر أ: margin-bottom: 30px
  ---------------------------  <- المسافة الحقيقية على الشاشة هي 30px (وليس 50px!)
  عنصر ب: margin-top: 20px
```

### قواعد انهماك الهوامش:
- يحدث فقط في الهوامش الرأسية (`top` و `bottom`)، ولا يحدث أبداً في الهوامش الأفقية (`left` و `right`).
- لا يحدث بين عناصر Flexbox أو CSS Grid الحديثة.

---

## 💡 5. الإطار (Border) مقابل التحديد الخارجي (Outline)

- **`border`:** يحتل مساحة فيزيائية ضمن نموذج الصندوق ويؤثر على الحسابات.
- **`outline`:** يُرسم بالكامل خارج تدفق النموذج ولا يحجز أي مساحة إضافية.
- **نصيحة لإمكانية الوصول:** لا تقم بإلغاء `outline: none` أبداً لحقول الإدخال والأزرار إلا إذا وفرت بديلاً واضحاً لحالة التركيز `:focus-visible` لمن يتنقلون بلوحة المفاتيح.

---

## 🎯 ملخص وتحدي الدرس

- كل عنصر هو مستطيل يتكون من المحتوى، الحشو، الإطار، والهامش الخارجي.
- اجعل `box-sizing: border-box` الإعداد الشامل لجميع عناصر الموقع.
- انتبه لظاهرة انهماك الهوامش الرأسية.

**تحدي الدرس:** أنشئ عنصراً بعرض إجمالي `320px`، وإطار `2px` وحشو داخلي `16px`. افتح أدوات المطور (F12) في المتصفح وتحقق من تبويب Computed للتأكد من أن عرضه الإجمالي هو 320px بالضبط!
