## 📌 1. القوائم: هيكلة وتجميع العناصر

توفر لغة HTML ثلاثة أنواع من القوائم، كل منها يحمل غرضاً دلالياً محدداً:

### أ. القوائم غير المرتبة (`<ul>` - Unordered List):
تُستخدم عندما لا يكون لترتيب العناصر أهمية تسلسلية (تظهر بنقاط افتراضياً):
```html
<ul>
    <li>سياسة أمان المحتوى (CSP)</li>
    <li>سلامة الموارد الفرعية (SRI)</li>
    <li>بروتوكول النقل الآمن (HSTS)</li>
</ul>
```

### ب. القوائم المرتبة (`<ol>` - Ordered List):
تُستخدم عندما يكون للترتيب أو الخطوات تسلسل منطقي (تظهر بأرقام افتراضياً):
```html
<ol>
    <li>اكتشاف نقطة إدخال البيانات غير الموثوقة (Source)</li>
    <li>تتبع مسار انتقال البيانات عبر شجرة DOM</li>
    <li>وصول البيانات إلى موضع تنفيذ غير آمن (Sink)</li>
</ol>
```

### ج. قوائم الوصف والتعريفات (`<dl>` - Description List):
تُستخدم للمصطلحات ومعانيها أو أزواج المفتاح والقيمة:
```html
<dl>
    <dt>XSS</dt>
    <dd>حقن نصوص برمجية خبيثة تنفذ في متصفح الضحية.</dd>
    <dt>CSRF</dt>
    <dd>تزييف طلبات المستخدم لخداعه وتنفيذ إجراءات غير مرغوبة.</dd>
</dl>
```

## 📊 2. جداول البيانات المعيارية (`<table>`)

> ⚠️ **قاعدة ذهبية:** **إياك واستخدام الجداول لتخطيط وبناء هيكل الصفحة.** الجداول مخصصة حصرياً لعرض البيانات المجدولة ثنائية الأبعاد (صفوف وأعمدة).

### البنية الدلالية لجدول بيانات متاح وقابل للوصول:
```html
<table>
    <caption>تقرير التدقيق الأمني الفصلي</caption>
    <thead>
        <tr>
            <th scope="col">نوع الثغرة</th>
            <th scope="col">مستوى الخطورة</th>
            <th scope="col">حالة المعالجة</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <th scope="row">DOM XSS</th>
            <td>عالي</td>
            <td>تم الإصلاح</td>
        </tr>
        <tr>
            <th scope="row">Open Redirect</th>
            <td>منخفض</td>
            <td>قيد المراجعة</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="2">إجمالي الثغرات المدققة</td>
            <td>2</td>
        </tr>
    </tfoot>
</table>
```

### متطلبات إمكانية الوصول للجداول:
- **`<caption>`:** عنوان توضيحي يشرح محتوى الجدول لمستخدمي قارئات الشاشة قبل القراءة.
- **`<thead>`، `<tbody>`، `<tfoot>`:** تقسيم هيكلي بين رؤوس الأعمدة، البيانات الفعلية، وملخص المجاميع.
- **`<th scope="col">` و `<th scope="row">`:** توضيح علاقة كل خلية بيانات بالعمود أو الصف الخاص بها لقارئات الشاشة.
- **`colspan` / `rowspan`:** دمج الخلايا أفقياً أو رأسياً.

---

## 🎯 ملخص وتحدي الدرس

- استخدم `<ul>` للعناصر غير المتسلسلة، `<ol>` للخطوات المرتبة، و`<dl>` للتعريفات.
- الجداول مخصصة للبيانات فقط وليست لتصميم القوالب، واستخدم دائماً `<caption>` و`scope`.

**تحدي الدرس:** أنشئ جدولاً يضم 3 ثغرات أمنية مع أعمدة: `اسم الثغرة`، `تصنيف OWASP`، و`معدل الخطورة CVSS`، مع استخدام الوسوم الدلالية الصحيحة.
