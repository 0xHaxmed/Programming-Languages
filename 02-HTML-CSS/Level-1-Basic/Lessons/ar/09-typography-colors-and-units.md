> 🌐 **Language / اللغة:** [English 🇬🇧](../en/09-typography-colors-and-units.md) | [العربية 🇸🇦](./09-typography-colors-and-units.md)

## 📌 1. وحدات القياس: المطلقة مقابل النسبية

اختيار وحدة القياس المناسبة في CSS ليس مسألة تفضيل شخصي، بل هو قرار هندسي يتعلق بسهولة الوصول (Accessibility) والتجاوب مع مختلف الشاشات:

| الوحدة | النوع | المرجع الأساسي للحساب | الاستخدام المثالي |
| :--- | :--- | :--- | :--- |
| `px` | مطلقة | وحدات البكسل الفيزيائية للشاشة | أطر الحدود الدقيقة (`1px solid`)، الأيقونات الثابتة |
| `rem` | نسبية | حجم خط العنصر الجذري (`html`) | **جميع أحجام الخطوط**، والمسافات الداخلية والخارجية |
| `em` | نسبية | حجم خط العنصر الحالي نفسه | الحشو الداخلي للأزرار ليتوسع تلقائياً مع حجم الخط |
| `%` | نسبية | أبعاد العنصر الحاوي الأب | النسب المئوية لأعمدة التخطيط |
| `vw` / `vh` | نسبية | 1% من عرض / ارتفاع نافذة المتصفح | لافتات البانر الكاملة والنوافذ المنبثقة |
| `dvh` | نسبية | الارتفاع الديناميكي للمتصفح في الموبايل | شاشات الهواتف لمنع تداخل شريط العنوان السفلي |

### ♿ قاعدة إمكانية الوصول الذهبية: `rem` للنصوص
لا تحدد أحجام الخطوط بوحدات `px` الثابتة. إذا قام مستخدم ضعيف البصر بتكبير خط النظام في هاتفه إلى 24px، فإن وحدة `px` تتجاهل تفضيل المستخدم وتجبره على قراءة الخط الصغير، بينما تستجيب وحدة `rem` وتتضاعف وفق رغبة المستخدم!

```css
html {
    font-size: 100%; /* تحترم الإعداد الافتراضي لمتصفح المستخدم (غالباً 16px) */
}

body {
    font-size: 1rem;       /* يعادل 16px */
    line-height: 1.6;     /* نسبة تباعد مريحة للعين */
}

h1 {
    font-size: 2.25rem;   /* يعادل 36px */
}
```

## 🎨 2. أنظمة تمثيل الألوان الحديثة في CSS

تدعم لغة CSS خيارات متعددة لتحديد الألوان:

### أ. النظام الست عشري (Hexadecimal):
```css
color: #0284c7;        /* 6 خانات: أحمر (02)، أخضر (84)، أزرق (c7) */
color: #0284c780;      /* 8 خانات مع شفافية بنسبة 50% في الخانتين الأخيرتين */
```

### ب. نظام RGB / RGBA:
```css
color: rgb(2, 132, 199);
color: rgb(2 132 199 / 75%); /* الصياغة الحديثة مع نسبة شفافية 75% */
```

### ج. نظام HSL (صبغة اللون، التشبع، الإضاءة):
أكثر النظم سهولة وإدراكاً للمصممين:
```css
/* الزاوية 0-360 على عجلة الألوان | التشبع 0-100% | الإضاءة 0-100% */
color: hsl(200, 98%, 39%);
color: hsl(200 98% 39% / 50%);
```
- هل تريد درجة أغمق لنفس اللون؟ قلل الإضاءة (`hsl(200, 98%, 25%)`).
- هل تريد درجة هادئة ناعمة؟ قلل نسبة التشبع فقط.

## 🔤 3. أساسيات الخطوط والطباعة (Typography)

```css
body {
    /* مصفوفة خطوط النظام الاحتياطية */
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif;
    font-weight: 400;         /* السماكة العادية (عريض: 700، متوسط: 600) */
    line-height: 1.6;         /* ارتفاع السطر المثالي لقراءة مريحة (1.5 إلى 1.7) */
    letter-spacing: -0.01em;  /* ضبط تباعد المحارف */
    color: #0f172a;           /* لون رمادي داكن هادئ (تجنب الأسود القاتم الصريح) */
}
```

### خصائص الطباعة الهامة:
- **`font-family`:** اكتب قائمة بالخطوط البديلة بالترتيب مع إنهاء القائمة دائماً بالنوع العام (`sans-serif` أو `serif`).
- **`line-height`:** المسافة الرأسية بين أسطر الفقرة؛ استخدم دائماً مضاعفاً عددياً مجرداً (مثل `1.6`) دون كتابة px.
- **`text-align`:** محاذاة النص (`left`, `center`, `right`, `justify`).

---

## 🎯 ملخص وتحدي الدرس

- استخدم `rem` لأحجام النصوص والمسافات العامة لاحترام إمكانية الوصول.
- استخدم `px` فقط للأطر والحدود الرفيعة.
- اتقن نظام HSL لتسهيل اشتقاق الألوان الثانوية.
- تجنب استخدام الأسود الفاحم `#000` على الخلفيات البيضاء واعتمد الرمادي الداكن (`#0f172a`).

**تحدي الدرس:** صمم صفحة مقال تضم عنواناً رئيسياً، عنواناً فرعياً، وفقرتين. اضبط كافة الخطوط بوحدة `rem` مع `line-height: 1.6`، واشتق لونين (أساسي وثانوي للحدود) باستخدام نظام HSL.
