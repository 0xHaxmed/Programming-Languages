## 📌 1. تضمين الصور (`<img>`)

وسم `<img>` هو عنصر فارغ (Self-closing) يُستخدم لتضمين الصور النقطية أو المتجهة داخل الصفحة:

```html
<img src="./assets/avatar.png" alt="صورة الملف الشخصي للمطور أحمد" width="300" height="300" loading="lazy">
```

### الخصائص الجوهرية للصور:
- **`src` (Source):** مسار ملف الصورة (نسبي أو مطلق).
- **`alt` (Alternative Text):** **إلزامي لإمكانية الوصول!** تقرأه برمجيات قارئات الشاشة للمكفوفين ويظهر عند فشل تحميل الصورة. إذا كانت الصورة زخرفية فقط، اكتب `alt=""` ليتجاهلها قارئ الشاشة.
- **`width` و `height`:** حدد الأبعاد الرقمية دائماً. هذا يتيح للمتصفح حجز المساحة مسبقاً قبل تنزيل الصورة، مما يقضي على مشكلة اهتزاز الصفحة **Cumulative Layout Shift (CLS)**!
- **`loading="lazy"`:** تأجيل تحميل الصور البعيدة حتى يقترب المستخدم من التمرير إليها، مما يسرع تحميل الصفحة بصورة هائلة.

## 🖼️ 2. الأشكال والرسومات البيانية الشارحة (`<figure>`, `<figcaption>`)

عند استخدام صورة كرسم توضيحي أو شكل هندسي مرفق بنص تفسيري، استخدم الوسوم الدلالية المخصصة:

```html
<figure>
    <img src="./diagram-xss-flow.png" alt="مخطط تدفق البيانات من المصدر إلى المصب" width="600" height="350">
    <figcaption>الشكل 1.1: مسار تدفق البيانات غير الموثوقة نحو دالة innerHTML.</figcaption>
</figure>
```

## 🎛️ 3. وسوم الصوت والفيديو المضمنة

توفر HTML5 مشغلات وسائط أصلية دون الحاجة لأي إضافات خارجية:

### أ. مشغل الفيديو (`<video>`):
```html
<video controls width="640" height="360" poster="./assets/preview-poster.jpg" preload="metadata">
    <source src="./videos/intro.mp4" type="video/mp4">
    <source src="./videos/intro.webm" type="video/webm">
    <p>متصفحك لا يدعم وسم الفيديو. <a href="./videos/intro.mp4">حمل المقطع من هنا</a>.</p>
</video>
```
- **`controls`:** يظهر أزرار التشغيل، الإيقاف، مستوى الصوت والتكبير الأصلية للمتصفح.
- **`poster`:** صورة المعاينة المصغرة قبل بدء التشغيل.
- **`<source>`:** يتيح للمتصفح اختيار أول صيغة متوافقة معه.

### ب. مشغل الصوت (`<audio>`):
```html
<audio controls>
    <source src="./audio/podcast-ep1.mp3" type="audio/mpeg">
    <source src="./audio/podcast-ep1.ogg" type="audio/ogg">
    متصفحك لا يدعم تشغيل المقاطع الصوتية.
</audio>
```

## 🛡️ 4. تحذير أمني خطير: ملفات SVG وثغرات Stored XSS

ملفات SVG هي صور متجهة مبنية على لغة XML. على عكس صور JPG أو PNG، **يمكن لملف SVG احتواء أكواد جافا سكريبت تنفيذية**:

```xml
<!-- ملف SVG خبيث -->
<svg xmlns="http://www.w3.org/2000/svg">
    <circle cx="50" cy="50" r="40" fill="red" />
    <script>alert(document.cookie)</script>
</svg>
```

### قواعد الحماية الصارمة:
1. عند عرض الـ SVG عبر وسم `<img src="icon.svg">`، يقوم المتصفح تلقائياً بتعطيل الأكواد البرمجية بداخله لأسباب أمنية.
2. لكن إذا سمح موقع للمستخدمين برفع ملفات SVG وعرضها بشكل مباشر (`<svg>`) أو تم فتح الملف برابط مباشر بنوع `image/svg+xml`، ستعمل جافا سكريبت ويحدث اختراق **Stored Cross-Site Scripting (XSS)** فوراً!
3. لا تسمح برفع ملفات SVG من مستخدمين غير موثوقين دون فحص وتنقية عميقة في السيرفر.

---

## 🎯 ملخص وتحدي الدرس

- اكتب دائماً وصفاً حقيقياً في خاصية `alt`.
- حدد `width` و `height` للحفاظ على استقرار أبعاد الصفحة.
- استخدم `loading="lazy"` لتسريع الأداء.
- تعامل بحذر أمني فائق مع ملفات الصور من نوع SVG.

**تحدي الدرس:** أنشئ قسماً للوسائط يضم صورة توضيحية داخل `<figure>` مع وصف `<figcaption>`، ومشغل فيديو HTML5 أصلياً مع وسوم `<source>`.
