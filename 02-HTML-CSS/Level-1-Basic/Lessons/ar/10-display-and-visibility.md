# 10 - أنماط العرض وإخفاء العناصر في CSS (Display & Visibility)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/10-display-and-visibility.md) | [العربية 🇸🇦](./10-display-and-visibility.md)

---

## 📌 1. خاصية العرض `display`

تتحكم خاصية `display` في كيفية تعامل المتصفح مع العنصر في تدفق المستند الطبيعي، وكيفية تنظيم العناصر الفرعية داخله.

```
 العناصر الكتلية Block (تشغل كامل العرض المتاح، وتبدأ بسطر جديد)
 ┌────────────────────────────────────────────────────────────┐
 │ <div>, <p>, <section>, <h1>                                │
 └────────────────────────────────────────────────────────────┘

 العناصر السطرية Inline (تتدفق أفقياً متجاورة جنباً إلى جنب)
 ┌──────────┐ ┌──────────┐ ┌──────────┐
 │  <span>  │ │   <a>    │ │ <strong> │
 └──────────┘ └──────────┘ └──────────┘
```

---

## 🔍 2. أنماط العرض الكلاسيكية الثلاثة

| قيمة الخاصية | هل تبدأ بسطر جديد؟ | هل تحترم `width` / `height`؟ | هل تحترم الهوامش الرأسية `margin-top/bottom`؟ | أشهر الوسوم الافتراضية |
| :--- | :---: | :---: | :---: | :--- |
| `block` | **نعم** | **نعم** | **نعم** | `div`, `p`, `h1`-`h6`, `ul`, `section` |
| `inline` | **لا** | **لا** | **لا** (أفقياً فقط) | `span`, `a`, `strong`, `em`, `code` |
| `inline-block` | **لا** | **نعم** | **نعم** | الأزرار، شارات التسمية، أغلفة الأيقونات |

### تحويل سلوك العناصر برمجياً:
يمكنك تحويل أي عنصر HTML ليعمل بنمط آخر بواسطة CSS:
```css
/* تحويل رابط عادي ليتصرف كزر بعرض وحشو داخلي مخصص */
a.cta-button {
    display: inline-block;
    padding: 0.75rem 1.5rem;
    width: 200px;
    text-align: center;
}
```

## 👻 3. طرق إخفاء العناصر: المقارنة الهندسية والأمنية

اختيار أسلوب إخفاء العنصر يحمل تبعات حاسمة على التخطيط، إمكانية الوصول، والأمان:

```
  عنصر طبيعي ظاهر            display: none           visibility: hidden        opacity: 0
┌────────────────┐                                ┌────────────────┐       ┌────────────────┐
│  [ عنصر ظاهر ] │       (يُحذف العنصر تماماً من   │ [عنصر غير مرئي]│       │ [عنصر شفاف كلياً]
│                │        شجرة العرض ولا يحجز أي  │                │       │  (ما زال يستقبل│
│                │            مساحة 0px)          │ (المساحة محجوزة)│       │  النقرات!)     │
└────────────────┘                                └────────────────┘       └────────────────┘
```

| الأسلوب | هل يحجز مساحة على الشاشة؟ | هل تراه قارئات الشاشة؟ | هل يقبل النقر والتفاعل؟ | البعد الأمني والاستخدام |
| :--- | :---: | :---: | :---: | :--- |
| `display: none;` | **لا** | **لا** (يتجاهله تماماً) | **لا** | القوائم المنسدلة، النوافذ المخفية |
| `visibility: hidden;` | **نعم** (تبقى فجوة فارغة) | **لا** | **لا** | حجز المكان مؤقتاً |
| `opacity: 0;` | **نعم** | **نعم** (أو جزئياً) | **نعم! (خطير أمنياً)** | التأثيرات الحركية، وثغرات **Clickjacking**! |

> 🛡️ **إضاءة أمنية خطيرة (هجمات Clickjacking):** في هجمات خطف النقرات، يضع المهاجم نافذة `iframe` غير مرئية بخاصية `opacity: 0` فوق زر بريء جذاب (مثل: "اضغط للمشاهدة"). يظن المستخدم أنه ينقر على الفيديو بينما هو في الحقيقة ينقر على زر مخفي ينفذ تحويلاً بنكياً أو يغير بريده الإلكتروني! سنتعلم كيفية سد هذه الثغرة جذرياً في المستوى الثالث.

## 🚀 4. أنظمة التخطيط الحديثة: Flexbox و Grid

بينما يتحكم `block` و `inline` في التدفق الفردي، تُبنى التطبيقات المعاصرة متعددة الأعمدة عبر:
- **`display: flex;`** — نظام المحاذاة والتدفق أحادي البعد.
- **`display: grid;`** — نظام المخططات الهندسية ثنائي الأبعاد (صفوف وأعمدة).

هذان المحركان هما محور تركيزنا الشامل في **المستوى الثاني - Foundation**!

---

## 🎯 ملخص وتحدي الدرس

- عناصر `block` تشغل السطر كاملاً، `inline` تتدفق مع النص، و`inline-block` تدمج السلوك السطري مع تحديد الأبعاد.
- فرّق بدقة بين الإخفاء الكامل (`display: none`)، وحجز المساحة (`visibility: hidden`)، والشفافية التفاعلية (`opacity: 0`).
- احذر من خطورة العناصر الشفافة التفاعلية لتجنب الوقوع في فخ الـ Clickjacking.

**تحدي الدرس:** أنشئ شريط تنقل يحتوي على قائمة غير مرتبة `<ul>` وقم بتحويل عناصر القائمة `<li>` من `display: block` إلى `display: inline-block` لتجلس جنباً إلى جنب مع حشو وتأثير hover أنيق.
