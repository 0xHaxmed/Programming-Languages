## 🎯 نظرة عامة على المشروع
يقدم مشروع المستوى الثالث التتويجي لوحة تحكم أمنية سيبرانية احترافية بمستوى المشاريع المؤسسية الكبرى: **لوحة تحكم CyberCommand**، المصممة لتجسيد التكامل بين **معمارية BEM**، **نظام سمات متغيرات CSS الديناميكي**، **معايير إمكانية الوصول العالمية WCAG 2.1 AA**، و**التحصين الأمني لواجهات الويب**.

### المزايا المعمارية والأمنية المحققة في المشروع:
1. **تطبيق صارم لمنهجية BEM:** تقسيم المكونات بدقة فائقة إلى كتل (`.dashboard`, `.metric-card`, `.panel`)، عناصر تابعة (`.metric-card__value`, `.panel__title`)، ومعدلات حالة (`.btn--outline`, `.badge--success`)، مما يضمن ثبات نقاط الأولوية عند `(0, 0, 1, 0)` في كامل ملف التنسيق والقضاء على كلمة `!important`.
2. **نظام سمات ديناميكي بالكامل:** مبني عبر متغيرات CSS الأصلية تحت سمتي `[data-theme="dark"]` و `[data-theme="light"]`، مما يتيح التبديل الفوري بين الوضع الليلي والنهاري دون وميض أو تعديل أكواد المكونات.
3. **مطابقة تامة لإمكانية الوصول (WCAG 2.1 AA):** معالم هيكلية مقروءة لقارئات الشاشة (`<header>`, `<aside>`, `<main>`, `<footer>`)، وتسمية الأزرار عبر `aria-label`، وحجب الأيقونات الزخرفية بـ `aria-hidden="true"`، مع إطار تركيز ناصع التباين `:focus-visible` لمستخدمي لوحة المفاتيح.
4. **التحصين الدفاعي للواجهة:** تطبيق توجيهات سياسة أمان المحتوى CSP، وأبعاد ثابتة للصور، والتحقق التلقائي من القائمة المرجعية للأمان.

## 🚀 كيفية تشغيل ومعاينة المشروع

1. افتح ملف `index.html` في متصفحك:
   ```powershell
   Start-Process chrome.exe "E:\Programming Languages\02-HTML-CSS\Level-3-Advanced-and-Security\Final-Project\index.html"
   ```
2. انقر على زر **"Switch Theme"** في الترويسة للتبديل اللحظي بين الوضعين الداكن والفاتح.
3. اضغط على مفتاح `Tab` في لوحة المفاتيح للتنقل بين الأزرار والروابط ولاحظ إطار التركيز عالي الوضوح.
4. افحص ملف التنسيق `styles.css` في أدوات المطور للتأكد من نظافة محددات BEM المسطحة تماماً.
