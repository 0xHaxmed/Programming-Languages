# 04 - عزل نوافذ Iframe وحماية التطبيقات من هجمات Clickjacking

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/04-iframe-sandboxing-and-clickjacking.md) | [العربية 🇸🇦](./04-iframe-sandboxing-and-clickjacking.md)

---

## 📌 1. سلاح الـ `<iframe>` ذو الحدين

يسمح عنصر `<iframe>` (Inline Frame) بتضمين صفحة ويب خارجية مستقلة تماماً داخل الصفحة الحالية. وعلى الرغم من أهميته في بوابات الدفع الإلكتروني، وتضمين الخرائط ومقاطع الفيديو، إلا أن نوافذ Iframe غير المقيدة تفتح أبواباً واسعة للهجمات الأمنية الخطيرة.

---

## 🛡️ 2. خاصية `sandbox`: تطبيق مبدأ الصلاحيات الدنيا

افتراضياً، يعمل أي موقع مضمن داخل iframe بكامل صلاحياته: يستطيع تشغيل أكواد جافا سكريبت، إرسال النماذج، فتح نوافذ منبثقة، وتوجيه الصفحة الأصلية.

قدمت HTML5 خاصية **`sandbox`** التي تضع الصفحة المضمنة داخل بيئة معزولة ومجردة من كافة الصلاحيات:

```html
<!-- أقصى درجات العزل: تعطيل جافا سكريبت، النماذج، الكوكيز، والنوافذ المنبثقة كلياً -->
<iframe src="https://untrusted-partner.com/widget" sandbox></iframe>
```

### استعادة الصلاحيات بدقة وتدرج (Granular Flags):
يمكنك منح الصلاحيات الضرورية فقط التي يحتاجها العنصر:

| الراية (Flag) | الصلاحية الممنوحة |
| :--- | :--- |
| `allow-scripts` | السماح بتشغيل أكواد جافا سكريبت داخل الإطار. |
| `allow-same-origin` | السماح للصفحة بالاحتفاظ بنطاقها الأصلي للوصول إلى الكوكيز والتخزين المحلي. |
| `allow-forms` | السماح بإرسال النماذج من داخل الإطار. |
| `allow-popups` | السماح بفتح نوافذ منبثقة عبر `window.open`. |
| `allow-top-navigation` | السماح للإطار بإعادة توجيه الصفحة الأصلية الحاوية له. |

```html
<!-- إطار معزول ومحصن -->
<iframe src="https://reports.partner.com" 
        sandbox="allow-scripts allow-forms" 
        title="أداة التقارير التحليلية">
</iframe>
```

> ⚠️ **تحذير أمني خطير للغاية:** **إياك والجمع بين `allow-scripts` و `allow-same-origin` معاً عند تضمين محتوى غير موثوق من نفس نطاق موقعك!** في حال وجودهما معاً، يمكن لكود جافا سكريبت داخل الإطار حذف خاصية `sandbox` برمجياً وكسر العزل بالكامل والسيطرة على الموقع!

## 🎭 3. هجمات خطف النقرات (Clickjacking / UI Redressing)

**خطف النقرات (Clickjacking)** هو هجوم خبيث يقوم فيه المهاجم بتضمين موقع الضحية الحقيقي (مثل: صفحة "تحويل أموال" في البنك أو "حذف الحساب") داخل نافذة `<iframe>` شفافة تماماً موضوعة فوق لعبة أو زر جذاب:

```
  ما يراه المستخدم الضحية على موقع المهاجم
 ┌────────────────────────────────────────────────────────┐
 │   "اضغط هنا لربح جائزة نقدية فورية!"                   │
 │   ┌───────────────────────────┐                        │
 │   │     [ العب واربح الآن ]    │                        │
 │   └───────────────────────────┘                        │
 └────────────────────────────────────────────────────────┘

  ما ينقر عليه المستخدم في الحقيقة (إطار بنكي شفاف تماماً: opacity: 0; z-index: 9999)
 ┌────────────────────────────────────────────────────────┐
 │   بوابة البنك الإلكترونية                              │
 │   ┌───────────────────────────┐                        │
 │   │  [ تأكيد تحويل 5000 دولار] │ ◄── النقرة تستقر هنا! │
 │   └───────────────────────────┘                        │
 └────────────────────────────────────────────────────────┘
```

نظراً لأن المستخدم مسجل دخوله مسبقاً في البنك، يرسل المتصفح ملفات تعريف الارتباط (Session Cookies) مع النقرة، فيتم التحويل البنكي دون علمه!

---

## 🔒 4. حماية وتأمين موقعك من هجمات Clickjacking

لمنع المواقع الخبيثة من تضمين صفحات موقعك الحساسة داخل أي iframe:

### أ. المعيار العالمي الحديث: سياسة أمان المحتوى (`frame-ancestors`)
أرسل ترويسة الـ HTTP التالية مع كافة صفحات موقعك:
```http
# منع أي موقع في العالم من تضمين صفحاتنا
Content-Security-Policy: frame-ancestors 'none';

# أو السماح بالتضمين لنطاق موقعنا فقط:
Content-Security-Policy: frame-ancestors 'self';
```

### ب. الترويسة القديمة المتوافقة: `X-Frame-Options`
لدعم المتصفحات القديمة:
```http
X-Frame-Options: DENY
# أو
X-Frame-Options: SAMEORIGIN
```

---

## 🎯 ملخص وتحدي الدرس

- اعزل أي نافذة iframe غير موثوقة باستخدام خاصية `sandbox`.
- لا تجمع أبداً بين `allow-scripts` و `allow-same-origin` على نفس النطاق.
- احمِ موقعك من هجمات Clickjacking بفرض ترويسة `frame-ancestors 'none'`.

**تحدي الدرس:** أنشئ ملف HTML يحاول تضمين موقع خارجي شهير داخل `<iframe>`. افتح كونسول المتصفح (F12) وشاهد كيف يرفض المتصفح عرض الصفحة مع إظهار رسالة الخطأ الأمني الخاصة بسياسة `frame-ancestors`.
