# 03 - إمكانية الوصول للويب ومعايير WCAG و ARIA (Web Accessibility)

## 📌 1. المبادئ القانونية والأخلاقية لإمكانية الوصول (a11y)

تهدف **إمكانية الوصول الرقمي (Web Accessibility - a11y)** إلى ضمان قدرة جميع الأشخاص، بما في ذلك ذوي الإعاقات البصرية، الحركية، السمعية، والإدراكية، على استخدام تطبيقات الويب واستيعابها والتفاعل معها بسهولة. وفقاً لمعيار **WCAG 2.1 Level AA العالمي**، تعد إمكانية الوصول التزاماً أخلاقياً ومطلباً قانونياً صارماً في معظم دول العالم.

### مبادئ POUR الأربعة:
1. **قابل للإدراك (Perceivable):** تقديم المعلومات بطرق يمكن للمستخدم استيعابها بحواسه (نصوص بديلة للصور، تباين ألوان كافٍ).
2. **قابل للتشغيل (Operable):** إمكانية تشغيل كافة عناصر الواجهة والتنقل عبر لوحة المفاتيح دون الوقوع في فخاخ برمجية.
3. **قابل للفهم (Understandable):** وضوح النصوص وسهولة توقع سلوك الأزرار والنماذج.
4. **متين ومستقر (Robust):** التوافق التام مع برمجيات قارئات الشاشة والتقنيات المساعدة.

## 🎨 2. نسب تباين الألوان (Color Contrast - معيار WCAG AA)

يجب أن تحافظ النصوص على تباين لوني كافٍ مع لون الخلفية لضمان قراءتها لمن يعانون من ضعف البصر أو عمى الألوان:

```
 نسب التباين الإلزامية وفق معيار WCAG Level AA
 ┌───────────────────────────┬────────────────────────────────┐
 │ تصنيف النص                │ الحد الأدنى لنسبة التباين       │
 ├───────────────────────────┼────────────────────────────────┤
 │ النصوص العادية (< 18pt)   │ 4.5 : 1                        │
 │ النصوص الكبيرة (>= 18pt)  │ 3.0 : 1                        │
 │ مكونات الواجهة والأطر     │ 3.0 : 1                        │
 └───────────────────────────┴────────────────────────────────┘
```

> 🛠️ **أداة الفحص:** افحص التباين دائماً عبر منتقي الألوان في أدوات مطور كروم (Elements -> Color Picker) للتأكد من ظهور علامتي الصح الخضراء (AA & AAA).

## ⌨️ 3. التنقل بلوحة المفاتيح ومؤشر التركيز (Focus Indicator)

يجب أن يتمكن المستخدم من الوصول لكافة الروابط والأزرار والحقول وتفعيلها باستخدام **لوحة المفاتيح وحدها** (عبر أزرار `Tab` و `Shift+Tab` و `Enter` و `Space`).

### قاعدة `:focus-visible` الإلزامية:
إياك وإلغاء مؤشر التركيز بـ `outline: none` دون توفير بديل واضح وعالي التباين:
```css
/* إطار تركيز ناصع ومتاح لمستخدمي لوحة المفاتيح */
button:focus-visible, 
a:focus-visible, 
input:focus-visible {
    outline: 2px solid #0284c7;
    outline-offset: 3px;
}
```

### استخدام خاصية `tabindex`:
- `tabindex="0"`: إدراج عنصر غير تفاعلي في التسلسل الطبيعي لزر Tab.
- `tabindex="-1"`: جعل العنصر قابلاً للاستهداف برمجياً عبر جافا سكريبت مع استبعاده من زر Tab.
- ❌ **نمط خاطئ:** `tabindex="1+"` (الأرقام الموجبة). لا تستخدم الأرقام الموجبة أبداً لأنها تدمر الترتيب المنطقي لقراءة الصفحة.

## 🏷️ 4. معيار WAI-ARIA للمكونات التفاعلية المتقدمة

> 📜 **القاعدة الأولى في ARIA:** **"عدم استخدام ARIA أفضل بكثير من استخدام ARIA خاطئة."** استخدم دائماً وسوم HTML الأصلية (`<button>`، `<dialog>`، `<nav>`) قبل التفكير في إضافة خصائص ARIA مخصصة.

### خصائص ARIA الأساسية:

### أ. خاصية `aria-label` (لأزرار الأيقونات):
عندما يحتوي الزر على أيقونة فقط دون نص صريح، تصبح قارئات الشاشة عاجزة عن نطق وظيفته:
```html
<!-- قارئ الشاشة ينطق: "إغلاق النافذة، زر" -->
<button type="button" class="btn-close" aria-label="إغلاق النافذة المنبثقة">
    <span aria-hidden="true">&times;</span>
</button>
```

### ب. خاصية `aria-hidden="true"` (لإخفاء الزخارف والرموز):
تمنع قارئات الشاشة من قراءة الرموز التعبيرية أو الأيقونات الجمالية:
```html
<button>
    <span aria-hidden="true">🔒</span>
    <span>تسجيل الدخول الآمن</span>
</button>
```

### ج. خاصية `aria-expanded` (للقوائم المنسدلة):
تخبر المستخدم بحالة القائمة إن كانت مغلقة أم مفتوحة:
```html
<button aria-expanded="false" aria-controls="audit-details">
    عرض تفاصيل الفحص
</button>
<div id="audit-details" hidden>...</div>
```

### د. المناطق الحية `aria-live="polite"`:
تعلن التحديثات اللحظية (كالرسائل التنبيهية ونتائج البحث) دون مقاطعة كلام القارئ الصوتي الحالي:
```html
<div class="status-msg" aria-live="polite">
    اكتمل الفحص بنجاح: لم يتم العثور على أي تهديدات.
</div>
```

## 🎯 ملخص وتحدي الدرس

- التزم بنسبة تباين 4.5:1 للنصوص العادية لتحقيق معيار WCAG AA.
- وفر دائماً إطار تركيز بصرياً عبر `:focus-visible`.
- استخدم `aria-label` لتعريف أزرار الأيقونات التي لا تحوي نصوصاً.
- احجب الأيقونات التجميلية عبر `aria-hidden="true"`.

**تحدي الدرس:** أنشئ زراً يحوي أيقونة حذف بدون نص، وقم بتهيئته لقارئات الشاشة عبر `aria-label` وإخفاء الأيقونة بـ `aria-hidden="true"`، مع إطار تركيز ناصع عبر `:focus-visible`.
