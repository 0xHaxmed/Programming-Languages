## 📌 1. مخاطر سلاسل الإمداد: اختراق سيرفرات الـ CDN

تعتمد تطبيقات الويب الحديثة بكثافة على تحميل ملفات التنسيق والمكتبات الخارجية من شبكات توزيع المحتوى العامة (CDNs):

```html
<link rel="stylesheet" href="https://cdn.example.com/styles.css">
```

### الخطر الأمني:
ماذا لو تم اختراق مزود الـ CDN، أو قام موظف بتعديل الملف، أو تم التلاعب بنظام الـ DNS؟ سيتم تحميل الكود الخبيث وتشغيله تلقائياً في متصفحات ملايين المستخدمين لشركتك!

---

## 🔒 2. معيار سلامة الموارد الفرعية (SRI)

**سلامة الموارد الفرعية (Subresource Integrity - SRI)** هو معيار أمان يُمكّن المتصفحات من التحقق التشفيري من أن الملفات المحملة من مصادر خارجية لم تتعرض لأي تعديل أو تلاعب خبيث:

```html
<link rel="stylesheet" 
      href="https://cdn.jsdelivr.net/npm/normalize.css@8.0.1/normalize.css" 
      integrity="sha256-WAgYcAck1C1/zEl5P9BkTWnTz02J869f214Ckvypz0E=" 
      crossorigin="anonymous">
```

### آلية العمل التشفيرية:
1. توليد بصمة تجزئة تشفيرية (Cryptographic Hash) بصيغة base64 لمحتوى الملف باستخدام خوارزميات `sha256` أو `sha384` أو `sha512`.
2. إضافة البصمة للوسم عبر خاصية `integrity="..."` مع إضافة `crossorigin="anonymous"`.
3. يقوم المتصفح بتنزيل الملف، وحساب بصمته التشفيرية محلياً، ومقارنتها بالبصمة المكتوبة في الكود.
4. **إذا اختلف محرف واحد فقط**، يرفض المتصفح تنفيذ الملف نهائياً ويطلق تحذيراً أمنياً صارماً في الكونسول!

## 🛡️ 3. توجيهات سياسة أمان المحتوى (CSP) الخاصة بـ HTML و CSS

تعتبر **سياسة أمان المحتوى (CSP)** خط الدفاع الأقوى لحماية واجهات HTML و CSS من هجمات XSS، والعلامات العالقة، وتسريب البيانات، وخطف النقرات.

### الترويسة القياسية المقترحة لحماية الواجهة:
```http
Content-Security-Policy: 
    default-src 'self';
    script-src 'self';
    style-src 'self';
    img-src 'self';
    font-src 'self';
    frame-ancestors 'none';
    form-action 'self';
    base-uri 'self';
```

### تفكيك توجيهات الواجهة الأمامية:
- **`style-src 'self'`:** حظر وسوم `<style>` الخام والتنسيق المضمن (يقضي تماماً على هجمات تسريب البيانات عبر CSS!).
- **`frame-ancestors 'none'`:** منع أي موقع خارجي من تضمين صفحاتك داخل `<iframe>` (القضاء الجذري على Clickjacking).
- **`base-uri 'self'`:** منع هجمات حقن وسم القاعدة (`<base href="https://attacker.com">`) الذي يغير مسار كافة الروابط النسبية في موقعك نحو سيرفر المهاجم!
- **`form-action 'self'`:** منع المهاجم من تغيير وجهة النماذج (`<form action="...">`) لسرقة البيانات المدخلة.

---

## 🎯 ملخص وتحدي الدرس

- أضف بصمات SRI التشفيرية لكل ملف خارجي يُجلب من CDN.
- امنع استخدام `'unsafe-inline'` في `style-src` لتعطيل استغلال الـ CSS.
- حصّن النماذج والروابط بتوجيهات `form-action 'self'` و `base-uri 'self'`.

**تحدي الدرس:** احسب بصمة الهاش التشفيرية لملف CSS خارجي، وضمنه مع خاصية `integrity="sha256-..."`. غير حرفاً واحداً في الملف وشاهد كيف يمنع المتصفح تطبيقه حمايةً للمستخدم.
