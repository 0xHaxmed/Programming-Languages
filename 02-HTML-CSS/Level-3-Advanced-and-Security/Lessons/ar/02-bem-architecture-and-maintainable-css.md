# 02 - معمارية BEM المنظمة وتجنب حروب الأولوية (BEM Architecture)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/02-bem-architecture-and-maintainable-css.md) | [العربية 🇸🇦](./02-bem-architecture-and-maintainable-css.md)

---

## 📌 1. فوضى الـ CSS غير المنظم وحروب الأولوية (Specificity Wars)

في المشاريع البرمجية الكبيرة، تتحول ملفات التنسيق تدريجياً إلى كابوس صيانة يسمى "حروب الأولوية":
```css
/* كود قديم شديد التداخل والهشاشة */
.sidebar div.widget > ul li a.active {
    color: red !important;
}
```
عندما يرغب مبرمج آخر في إعادة استخدام هذا الرابط داخل نافذة منبثقة، يجد أنه من المستحيل تعديل لونه دون كتابة محدد أطول أو اللجوء إلى كلمة `!important`، فتغرق الشيفرة في الفوضى.

جاءت منهجية **BEM (Block, Element, Modifier)** كمعيار تسمية عالمي يقضي جذرياً على تعارضات الأولوية، ويضمن نمطية المكونات، ويجعل أسماء الفئات توثق نفسها بنفسها.

---

## 🏗️ 2. تشريح منهجية BEM

```
  .block__element--modifier
   ├───┤ ├───────┤  ├──────┤
   الكتلة   العنصر    المعدل
```

### أ. الكتلة (Block - `.block`)
كيان مستقل قائم بذاته ويحمل معنى واضحاً بمفرده (مثل: `header`, `card`, `btn`, `menu`).
```html
<article class="card"></article>
```

### ب. العنصر (Element - `.block__element`)
جزء فرعي تابع للكتلة ولا يحمل معنى مستقلاً خارجها. يُفصل عن اسم الكتلة بـ **شرطتين سفليتين (`__`)**:
```html
<article class="card">
    <h2 class="card__title">تحليل السجلات</h2>
    <p class="card__description">مراجعة تقارير الحوادث الأمنية.</p>
</article>
```

### ج. المعدل (Modifier - `.block--modifier` أو `.block__element--modifier`)
خاصية أو راية تغير المظهر البصري، السمة، أو حالة الكتلة أو العنصر. يُفصل بـ **شرطتين متتاليتين (`--`)**:
```html
<!-- تنويع على مستوى الكتلة -->
<button class="btn btn--danger">حذف التقرير</button>

<!-- تنويع على مستوى حالة العنصر -->
<li class="menu__item menu__item--active">الرئيسية</li>
```

## 🛡️ 3. كيف تقضي BEM على حروب الأولوية؟

الميزة المعمارية المذهلة لمنهجية BEM: **كل محدد في ملف التنسيق يمتلك وزناً مسطحاً وموحداً تماماً: (0, 0, 1, 0)!**

```css
/* أكواد مسطحة، معزولة ومتوقعة السلوك */
.card {
    background: #ffffff;
    border-radius: 8px;
}

.card__title {
    font-size: 1.25rem;
}

.card--featured {
    border: 2px solid #0284c7;
}
```
لن تحتاج أبداً إلى تداخل المحددات (`.card h2`). وإذا قمت بنقل `.card__title` إلى داخل حاوية فرعية، فلن ينكسر التنسيق إطلاقاً!

---

## 🚫 4. أخطاء شائعة يجب تجنبها في BEM

1. **تجنب تكرار الشرطات السفلية المتتالية:**
   - ❌ `.card__header__title` (لا تعكس تسلسل شجرة الـ DOM!).
   - ✅ `.card__title` (اجعل العناصر مسطحة تتبع الكتلة الأم مباشرة).
2. **لا تنسق وسوم HTML الخام داخل كتل BEM:**
   - ❌ `.card h2`
   - ✅ `.card__title`

---

## 🎯 ملخص وتحدي الدرس

- تعني BEM: الكتلة (Block)، العنصر (Element)، والمعدل (Modifier).
- استخدم `__` للأجزاء التابعة و `--` للخصائص المتغيرة.
- تحافظ على ثبات الأولوية عند `(0, 0, 1, 0)` وتنهي الحاجة لـ `!important`.

**تحدي الدرس:** أعد صياغة شريط تنقل متداخل وقديم (`.nav ul li a`) باستخدام منهجية BEM النظيفة (`.nav`, `.nav__list`, `.nav__item`, `.nav__link`, `.nav__link--active`) مع كتابة تنسيقات CSS المسطحة المقابلة لها.
