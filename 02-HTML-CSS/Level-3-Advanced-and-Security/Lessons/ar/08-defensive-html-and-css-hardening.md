## 🛡️ 2. القائمة المرجعية للتحصين الهندسي

### 1. نظافة المستند والبيانات الوصفية
- [ ] يبدأ المستند دائماً بـ `<!DOCTYPE html>`.
- [ ] يعلن وسم `<html lang="...">` بوضوح عن لغة الصفحة لقارئات الشاشة والـ SEO.
- [ ] كتابة `<meta charset="UTF-8">` كأول سطر في `<head>` لمنع تجاوزات ترميز UTF-7 القديمة.
- [ ] ضبط وسم الموبايل: `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.

### 2. الروابط والتنقل الآمن
- [ ] كل رابط خارجي بـ `target="_blank"` يتضمن إجبارياً `rel="noopener noreferrer"`.
- [ ] خلو الكود تماماً من روابط `href="javascript:..."` (واستبدالها بـ `<button type="button">`).
- [ ] كتابة نصوص دلالية واضحة للروابط وتجنب عبارات "اضغط هنا".

### 3. الوسائط والملفات
- [ ] كل صورة غير زخرفية تملك وصفاً دلالياً حقيقياً عبر `alt` (أو `alt=""` للصور الزخرفية فقط).
- [ ] تحديد أبعاد صريحة `width` و `height` لمنع اهتزاز الصفحة عند التحميل (CLS).
- [ ] معالجة ملفات SVG المرفوعة من المستخدمين بأمان أو تنزيلها بـ `Content-Disposition: attachment` لمنع ثغرات Stored XSS.

### 4. النماذج وحقول الإدخال
- [ ] ربط كل حقل إدخال بتسمية واضحة وصريحة عبر `<label for="...">`.
- [ ] استخدام `method="POST"` لكافة النماذج الحساسة وتجنب `GET` تماماً.
- [ ] نماذج رفع الملفات تعلن صراحة عن `enctype="multipart/form-data"`.
- [ ] تحديد سياق حقول الاعتماد عبر `autocomplete="current-password"` أو `new-password` أو `one-time-code`.
- [ ] قيام السيرفر الخلفي بفحص وتنقية 100% من المدخلات دون الوثوق بفحص المتصفح.

### 5. إطارات Iframe والعزل
- [ ] تقييد أي إطار iframe خارجي بخاصية `sandbox`.
- [ ] عدم الجمع نهائياً بين `allow-scripts` و `allow-same-origin` على نفس النطاق.
- [ ] إرسال ترويسة `Content-Security-Policy: frame-ancestors 'none'` لمنع Clickjacking.

### 6. معمارية CSS ومنع الحقن
- [ ] تفعيل `box-sizing: border-box` الشامل للقضاء على أخطاء حساب الأبعاد.
- [ ] تطبيق منهجية BEM للحفاظ على وزن أولوية مسطح `(0, 0, 1, 0)` وتجنب `!important`.
- [ ] منع طباعة أي نصوص CSS غير منقاة من المستخدمين (حجب ثغرات CSS Exfiltration).
- [ ] توفير إطار تركيز بصري عالي التباين عبر `:focus-visible` لمستخدمي لوحة المفاتيح.
- [ ] مطابقة تباين الألوان لمعيار WCAG 2.1 AA (نسبة 4.5:1 كحد أدنى).

### 7. سلاسل الإمداد وترويسات الأمان
- [ ] حماية ملفات CDN الخارجية ببصمات SRI التشفيرية (`integrity`) مع `crossorigin="anonymous"`.
- [ ] حظر استدعاء التنسيقات المضمنة `'unsafe-inline'` في سياسة الـ CSP.
- [ ] تقييد مسارات الروابط والنماذج عبر `base-uri 'self'` و `form-action 'self'`.

## 🎯 3. كيف تفحص أي صفحة ويب أمنياً في 5 دقائق

```
 مسار التدقيق الأمني السريع لواجهات الويب (5 دقائق)
 ┌────────────────────────────────────────────────────────────┐
 │ 1. افحص ترويسات الاستجابة: CSP، و frame-ancestors، و XFO    │
 │ 2. ابحث عن وسوم <a>: هل توجد روابط target="_blank" بلا rel؟│
 │ 3. راجع حقول النماذج: هل توجد أسرار مطبوعة في الـ DOM؟    │
 │ 4. ابحث عن التنسيقات المضمنة: وسوم <style> و style="..."   │
 │ 5. دقق في وسوم <iframe>: هل تم تطبيق قيود sandbox بشكل سليم؟│
 └────────────────────────────────────────────────────────────┘
```
