# 07 - تسمية المساحات في Grid والتجاوب التلقائي عبر Auto-Fit

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/07-css-grid-areas-and-alignment.md) | [العربية 🇸🇦](./07-css-grid-areas-and-alignment.md)

## 📌 1. رسم المخطط البصري عبر `grid-template-areas`

من أروع وأقوى ميزات CSS Grid هي إمكانية **تسمية المساحات (Named Grid Areas)**. فبدلاً من حساب أرقام الخطوط، يمكنك "رسم" شكل الصفحة حرفياً كنصوص مرئية:

```html
<div class="site-layout">
    <header class="header">ترويسة الموقع</header>
    <nav class="nav">شريط التنقل</nav>
    <main class="main">المحتوى الأساسي</main>
    <aside class="sidebar">الشريط الجانبي</aside>
    <footer class="footer">تذييل الموقع</footer>
</div>
```

```css
.site-layout {
    display: grid;
    grid-template-columns: 240px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header  header  header"
        "nav     main    sidebar"
        "footer  footer  footer";
    min-height: 100vh;
    gap: 1rem;
}

/* ربط كل عنصر باسم المنطقة في المخطط */
.header  { grid-area: header; }
.nav     { grid-area: nav; }
.main    { grid-area: main; }
.sidebar { grid-area: sidebar; }
.footer  { grid-area: footer; }
```

### استخدام النقطة (`.`) لترك خلية فارغة:
إذا أردت ترك خانة فارغة في الشبكة، اكتب نقطة:
```css
grid-template-areas:
    "header header"
    "main   ."
    "footer footer";
```

## 🚀 2. شبكات متجاوبة بالكامل دون أي Media Query (`auto-fit`)

يُعد هذا السطر الواحد في CSS من أعظم الابتكارات في هندسة واجهات الويب المعاصرة:

```css
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 1.5rem;
}
```

### كيف تعمل هذه التعويذة الهندسية؟
1. كلما اتسعت الشاشة، يضع المتصفح أكبر عدد ممكن من الأعمدة بعرض لا يقل عن `280px`.
2. إذا تبقت مساحة فارغة، تقوم نسبة `1fr` بتمديد البطاقات بالتساوي لملء الفراغ تماماً.
3. كلما ضاقت الشاشة (كالهواتف الذكية)، تلتف البطاقات تلقائياً وتقل الأعمدة حتى تصبح عموداً واحداً عريضاً على الموبايل—**دون كتابة استعلام `@media` واحد!**

## 🔍 3. الفرق الدقيق: `auto-fit` مقابل `auto-fill`

```
 عرض الحاوية: 1000px | عدد البطاقات: 2 (الحد الأدنى 200px لكل بطاقة)

 auto-fill (يحجز مسارات وهمية فارغة لبطاقات محتملة)
 ┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
 │   بطاقة 1    │   بطاقة 2    │ (خانة فارغة) │ (خانة فارغة) │ (خانة فارغة) │
 └──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘

 auto-fit (يقلص الخانات الفارغة إلى 0px ويمدد البطاقات الحالية لتملأ الصفحة!)
 ┌─────────────────────────────┬─────────────────────────────┐
 │           بطاقة 1           │           بطاقة 2           │
 └─────────────────────────────┴─────────────────────────────┘
```

- **`auto-fill`:** يحافظ على حجز المسارات الشاغرة حتى لو لم تكن هناك عناصر كافية لملئها.
- **`auto-fit` (الخيار الموصى به دائماً):** يسحق المسارات الفارغة ويوزع مساحتها على البطاقات الموجودة لتملأ الشاشة بأناقة.

---

## 🎯 4. محاذاة مسارات وخلايا الشبكة

| الخاصية | المحور | المستهدف |
| :--- | :--- | :--- |
| `justify-items` | المحور الأفقي السطري | محاذاة المحتوى داخل كل خلية منفردة (`start`, `center`, `end`, `stretch`). |
| `align-items` | المحور الرأسي الكتلي | المحاذاة الرأسية للمحتوى داخل كل خلية. |
| `justify-content` | المحور الأفقي العام | محاذاة مصفوفة الشبكة ككل داخل الحاوية الأب. |
| `align-content` | المحور الرأسي العام | محاذاة مصفوفة الشبكة ككل رأسياً داخل الحاوية. |

---

## 🎯 ملخص وتحدي الدرس

- تتيح `grid-template-areas` رسم هيكل الموقع كنصوص مقروءة ومرئية.
- احفظ قاعدة `repeat(auto-fit, minmax(280px, 1fr))` لإنشاء معارض بطاقات متجاوبة تلقائياً.
- افهم الفرق بين `auto-fit` (تمدد العناصر) و`auto-fill` (حفظ المسارات الشاغرة).

**تحدي الدرس:** أنشئ معرضاً للبطاقات يعرض 4 أعمدة على الشاشات الكبيرة، وعمودين على الأجهزة اللوحية، وعموداً واحداً على الهواتف باستخدام `repeat(auto-fit, minmax(250px, 1fr))` دون كتابة أي استعلام وسائط.
