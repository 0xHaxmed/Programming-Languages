# 09 - التعمق في تموضع العناصر (النسبي، المطلق، الثابت، واللاصق)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/09-css-positioning-deep-dive.md) | [العربية 🇸🇦](./09-css-positioning-deep-dive.md)

## 📌 1. التدفق الطبيعي مقابل الخروج عن التدفق (Normal Flow vs Out-of-Flow)

افتراضياً في لغة CSS، تُعرض العناصر وفق **التدفق الطبيعي للمستند (Normal Flow)** (`position: static`)، حيث تصطف العناصر الكتلية رأسياً والعناصر السطرية أفقياً.

تسمح لك خاصية `position` بإزاحة العناصر، أو سحبها بالكامل خارج التدفق الطبيعي وتحديد إحداثياتها بدقة جراحية عبر خصائص الإزاحة: `top`، `right`، `bottom`، `left`، أو الخاصية المدمجة `inset`.

## 🧭 2. الأنماط الخمسة لتموضع العناصر

```
 ┌────────────────┬─────────────────────┬──────────────────────┬───────────────────────────────┐
 │ النمط (Mode)   │ هل في التدفق الطبيعي؟│ بالنسبة إلى ماذا يتموضع؟│ الاستخدام النموذجي             │
 ├────────────────┼─────────────────────┼──────────────────────┼───────────────────────────────┤
 │ static         │ نعم                 │ التدفق الطبيعي للمستند │ السلوك الافتراضي لكافة العناصر │
 │ relative       │ نعم (يحجز مكانه)   │ مكانه الأصلي الطبيعي │ الإزاحات الطفيفة وسياق للأبناء│
 │ absolute       │ لا (يسقط من التدفق)  │ أقرب أب يحمل موضعاً  │ الشارات، النوافذ المنبثقة،    │
 │                │                     │ مخصصاً (!= static)   │ ومربعات التلميح Tooltips     │
 │ fixed          │ لا (يسقط من التدفق)  │ نافذة المتصفح ككل    │ أشرطة التنقل العلوية، إشعار كوكيز│
 │ sticky         │ نعم (حتى التمرير)   │ أقرب حاوية قابلة للتمرير│ رؤوس الجداول والأشرطة اللاصقة │
 └────────────────┴─────────────────────┴──────────────────────┴───────────────────────────────┘
```

## 🎯 3. النمط الهندسي الكلاسيكي: تثبيت المطلق فوق النسبي

أشهر وأكثر أنماط التموضع استخداماً في الويب: تثبيت شارة تنبيهية بنمط `absolute` فوق بطاقة بنمط `relative`:

```html
<div class="product-card">
    <span class="security-badge">جديد</span>
    <img src="shield.png" alt="درع الأمان">
    <h3>جدار الحماية المتقدم</h3>
</div>
```

```css
.product-card {
    position: relative; /* إلزامي: يؤسس نقطة الارتكاز المرجعية للإحداثيات! */
    width: 300px;
    padding: 1.5rem;
    border: 1px solid #cbd5e1;
}

.security-badge {
    position: absolute; /* يتموضع حصرياً داخل حدود .product-card */
    top: 12px;
    left: 12px;
    background-color: #ef4444;
    color: #ffffff;
    font-size: 0.75rem;
    padding: 0.25rem 0.5rem;
    border-radius: 4px;
}
```

> ⚠️ **خطأ شائع:** إذا نسيت كتابة `position: relative` على العنصر الأب، سيصعد العنصر الابن ذو `position: absolute` في شجرة الـ DOM حتى يصل إلى عنصر `<html>`، ليثبت نفسه في زاوية الشاشة الكلية للموقع!

## 📌 4. سحر التموضع اللاصق (`position: sticky`)

التموضع اللاصق هو هجين هندسي عبقري: يتصرف العنصر كعنصر نسبي طبيعي (`relative`) حتى يصل المستخدم بالتمرير إلى حد معين، فيتحول فوراً ليتصرف كعنصر ثابت (`fixed`)—**شريطة أن يظل محصوراً داخل حدود الأب الحاوي له فقط!**

```css
.table-header th {
    position: sticky;
    top: 0; /* يلتصق بأعلى الجدول أثناء تمرير بيانات الصفوف */
    background-color: #ffffff;
    z-index: 10;
}
```

## 🥞 5. لغز سياق التراكم (Stacking Context) و `z-index`

هل قمت يوماً بضبط `z-index: 999999` وتفاجأت بأن العنصر ما زال يقبع أسفل عنصر آخر؟

### السبب: سياقات التراكم المعزولة (Stacking Contexts)
سياق التراكم هو ترتيب طبقي ثلاثي الأبعاد معزول. أي عنصر يحمل `z-index: 9999` داخل حاوية تحمل `z-index: 1` **لن يستطيع أبداً** الظهور فوق حاوية شقيقة تحمل `z-index: 2`!

```
 سياق التراكم الجذري للموقع
 ├── الحاوية أ (z-index: 1)
 │   └── النافذة المنبثقة (z-index: 99999) ──┐
 └── الحاوية ب (z-index: 2)                  │
     └── عنصر الترويسة ──────────────────────┴───► الحاوية ب ستظهر في الأعلى حتماً!
```

### ما الذي ينشئ سياق تراكم جديد؟
- العناصر التي تحمل `position: relative/absolute` مع `z-index` غير `auto`.
- الشفافية `opacity` الأقل من `1`.
- التحويلات الحركية `transform` بقيمة غير `none`.
- الفلاتر `filter`.

---

## 🎯 ملخص وتحدي الدرس

- استخدم الأب `relative` كنقطة ارتكاز للابن `absolute`.
- استخدم `fixed` للواجهات العائمة على كامل الشاشة.
- استخدم `sticky` لرؤوس الجداول وأشرطة الأقسام.
- تذكر أن مقارنة `z-index` تتم فقط داخل نفس سياق التراكم.

**تحدي الدرس:** أنشئ مقالاً طويلاً قابلاً للتمرير يحتوي على جدول يلتصق رأسه في الأعلى عند التمرير (`position: sticky; top: 0`)، وبطاقة كاتب تحمل شارة إشعار مثبتة في الزاوية بواسطة `position: absolute`.
