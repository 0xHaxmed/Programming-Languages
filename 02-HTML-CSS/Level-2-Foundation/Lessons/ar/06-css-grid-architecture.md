# 06 - هندسة CSS Grid (المخططات الهيكلية ثنائية الأبعاد)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/06-css-grid-architecture.md) | [العربية 🇸🇦](./06-css-grid-architecture.md)

---

## 📌 1. محرك التخطيط ثنائي الأبعاد (Two-Dimensional Engine)

بينما صُمم نظام Flexbox للتدفق الخطي في بعد واحد (صف أو عمود)، يمثل **CSS Grid** أول محرك تخطيط **ثنائي الأبعاد بالكامل** في تاريخ لغة CSS. إنه يمنحك القدرة على هندسة وتوزيع العناصر عبر **الصفوف والأعمدة معاً في نفس الوقت**، مما يجعله الأساس المثالي لبناء صفحات المواقع الكاملة ولوحات التحكم المعقدة (Dashboards).

```
       عمود 1            عمود 2            عمود 3
  ┌────────────────┬────────────────┬────────────────┐
  │                │                │                │  صف 1
  ├────────────────┼────────────────┼────────────────┤
  │                │                │                │  صف 2
  ├────────────────┼────────────────┼────────────────┤
  │                │                │                │  صف 3
  └────────────────┴────────────────┴────────────────┘
```

---

## 🏗️ 2. تفعيل شبكة Grid وتحديد المسارات

يتم تفعيل سياق الشبكة بكتابة `display: grid` على العنصر الأب:

```html
<div class="dashboard-grid">
    <div class="card">الإحصائيات</div>
    <div class="card">سجلات الأمان</div>
    <div class="card">التنبيهات</div>
    <div class="card">التقارير</div>
</div>
```

```css
.dashboard-grid {
    display: grid;
    grid-template-columns: 200px 1fr 1fr; /* إنشاء 3 أعمدة */
    grid-template-rows: auto;              /* ارتفاع الصفوف يتكيف تلقائياً */
    gap: 1.5rem;                           /* المسافات بين الخلايا */
}
```

---

## 📏 3. وحدة الكسر النسبي (`fr`) ودالة التكرار `repeat()`

تمثل **وحدة الكسر النسبي (Fractional Unit - `fr`)** حصة نسبية من المساحة الفارغة المتبقية في الحاوية:

```css
/* 3 أعمدة متساوية: يحصل كل عمود على ثلث المساحة تماماً */
grid-template-columns: 1fr 1fr 1fr;

/* الصياغة النظيفة عبر دالة repeat(عدد_التكرار, حجم_المسار) */
grid-template-columns: repeat(3, 1fr);

/* تخطيط غير متماثل: شريط جانبي 260px والباقي يقسم بنسبة 2 إلى 1 */
grid-template-columns: 260px 2fr 1fr;
```

---

## 🛡️ 4. التجاوب المرن المحمي عبر `minmax()`

لمنع انكماش الأعمدة إلى درجة تجعل النصوص غير قابلة للقراءة:
```css
/* تتمدد الأعمدة بحرية لتملأ الفراغ، ولكنها لن تنكمش أبداً لأقل من 220px */
grid-template-columns: repeat(3, minmax(220px, 1fr));
```

---

## 🔢 5. خطوط الشبكة وتمدد الخلايا (Spanning Cells)

تُرقم خطوط الشبكة تصاعدياً بدءاً من `1` (أو تنازلياً بالسالب `-1` من الطرف المعاكس):

```
 خط 1             خط 2             خط 3             خط 4
   │                │                │                │
   ▼                ▼                ▼                ▼
   ┌────────────────┬────────────────┬────────────────┐
 1 │                │                │                │
   ├────────────────┼────────────────┼────────────────┤
 2 │                                 │                │
   │           (تمدد عبر عمودين)     │                │
   ├────────────────┼────────────────┼────────────────┤
 3 │                │                │                │
   └────────────────┴────────────────┴────────────────┘ 4
```

### تمديد العناصر عبر المسارات:
```css
/* تمدد العنصر عبر عمودين */
.hero-card {
    grid-column: 1 / 3;     /* يبدأ من الخط 1 وينتهي عند الخط 3 */
    /* أو الصياغة المختصرة: */
    grid-column: span 2;
}

/* تمدد العنصر ليشغل كامل عرض الشبكة أفقياً */
.full-width-banner {
    grid-column: 1 / -1;    /* يمتد من أول خط إلى آخر خط في الشبكة! */
}
```

## ⚖️ 6. المقارنة الهندسية: متى نختار Grid ومتى نختار Flexbox؟

| المعيار | نظام CSS Grid | نظام Flexbox |
| :--- | :--- | :--- |
| **الأبعاد** | **ثنائي الأبعاد (2D)** صفوف وأعمدة معاً | **أحادي البعد (1D)** صف أو عمود |
| **فلسفة التخطيط** | **التخطيط أولاً (Layout-First)** تبني الهيكل وتضع العناصر فيه | **المحتوى أولاً (Content-First)** حجم المحتوى يحدد التباعد |
| **الاستخدام المثالي** | هيكل الصفحات الكاملة، لوحات التحكم، معارض الصور | أشرطة التنقل العلوية، مجموعات الأزرار، محاذاة الأيقونات |

---

## 🎯 ملخص وتحدي الدرس

- يتحكم نظام Grid بالصفوف والأعمدة في وقت واحد.
- وحدة `fr` توزع المساحة المتبقية بنسب رياضية دقيقة.
- دالة `minmax()` تضمن بقاء الأعمدة ضمن حدود أبعاد آمنة.
- استخدم `grid-column: 1 / -1` لجعل العنصر يمتد بعرض الصفحة كاملاً.

**تحدي الدرس:** أنشئ شبكة معمارية من 12 عموداً (`grid-template-columns: repeat(12, 1fr)`). اجعل الترويسة تمتد على كامل الشبكة (`1 / -1`)، والشريط الجانبي يمتد لـ 3 أعمدة (`span 3`)، والمحتوى الرئيسي لـ 9 أعمدة (`span 9`).
