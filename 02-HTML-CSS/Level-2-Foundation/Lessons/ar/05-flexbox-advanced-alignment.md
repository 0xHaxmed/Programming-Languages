# 05 - احتراف Flexbox المتقدم (الالتفاف، التمدد والتقلص)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/05-flexbox-advanced-alignment.md) | [العربية 🇸🇦](./05-flexbox-advanced-alignment.md)

---

## 📌 1. الالتفاف متعدد الأسطر: خاصية `flex-wrap`

افتراضياً، تجبر حاوية Flexbox كافة العناصر على البقاء في **سطر واحد** (`flex-wrap: nowrap`)، حتى لو أدى ذلك إلى خروجها عن حدود الشاشة أو انضغاطها بشكل مشوه.

للسماح للعناصر بالالتفاف والانتقال لأسطر جديدة بسلاسة مع صغر الشاشة:

```css
.card-grid {
    display: flex;
    flex-wrap: wrap; /* السماح للعناصر بالنزول لسطر جديد عند ضيق المساحة */
    gap: 1.5rem;
}
```

- `nowrap` (الافتراضي): حشر كافة العناصر في سطر واحد دون التفات للمساحة.
- `wrap`: التفاف العناصر للأسفل في أسطر جديدة متعاقبة.
- `wrap-reverse`: التفاف العناصر للأعلى في أسطر معكوسة.

## 📐 2. ثلاثية أبعاد العناصر المرنة: `grow` و `shrink` و `basis`

يحسب العنصر المرن حجمه النهائي على الشاشة بناءً على ثلاث خصائص مترابطة:

```
 إجمالي المساحة المتاحة في الحاوية
 ┌────────────────────────────────────────────────────────────┐
 │  ┌───────────────┐ ┌───────────────┐ ┌──────────────────┐  │
 │  │ flex-grow: 1  │ │ flex-grow: 1  │ │  flex-grow: 2    │  │
 │  └───────────────┘ └───────────────┘ └──────────────────┘  │
 └────────────────────────────────────────────────────────────┘
```

### أ. البعد الأساسي الأولي (`flex-basis`):
يحدد الحجم الافتراضي الأولي للعنصر قبل توزيع المساحة المتبقية. يعمل كبديل متقدم لـ `width` في وضع الصف أو `height` في وضع العمود.
```css
.sidebar {
    flex-basis: 280px;
}
```

### ب. معامل التمدد لاستهلاك المساحة الزائدة (`flex-grow`):
يحدد نسبة استهلاك العنصر للمساحة الإضافية المتبقية في الحاوية مقارنة بأشقائه:
- `flex-grow: 0` (الافتراضي): يبقى العنصر بحجمه الأساسي ولا يتمدد.
- `flex-grow: 1`: يتمدد العنصر ليملأ أي فراغ متبقٍ.
- العنصر الذي يحمل `flex-grow: 2` سيحصل على **ضعف** المساحة الفارغة المتبقية مقارنة بالعنصر ذي `flex-grow: 1`.

### ج. معامل التقلص عند ضيق المساحة (`flex-shrink`):
يحدد مدى قابلية العنصر للانكماش عند ضيق المساحة في الحاوية:
- `flex-shrink: 1` (الافتراضي): ينكمش العنصر بنسبة متوازنة لمنع الفيضان.
- `flex-shrink: 0`: **يمنع انكماش العنصر نهائياً!** أمر جوهري للأيقونات والصور الشخصية لمنع تشوه أبعادها.

### 🌟 الاختصار القياسي المعتمد: `flex`
يُفضل دائماً استخدام الصياغة المدمجة للقيم الثلاث `flex: <grow> <shrink> <basis>`:
```css
.main-content {
    flex: 1 1 0%;    /* تمدد بحرية، انكمش عند الحاجة، وابدأ من 0 */
}

.fixed-sidebar {
    flex: 0 0 260px; /* لا تتمدد، لا تنكمش، واثبت دائماً على 260px */
}
```

## 🎯 3. تخصيص المحاذاة المنفردة عبر `align-self`

يمكن لأي عنصر مرن بمفرده تجاوز قاعدة `align-items` العامة المحددة في الحاوية الأم:

```css
.container {
    display: flex;
    align-items: center; /* كافة العناصر متوسطة رأسياً */
}

.special-badge {
    align-self: flex-start; /* هذا العنصر فقط يلتصق بالأعلى بمفرده! */
}
```

## ⚠️ 4. فخ إعادة الترتيب البصري وتأثيره على إمكانية الوصول

تتيح خاصية `order` إعادة ترتيب ظهور العناصر شكلياً:
```css
.first-in-dom {
    order: 2; /* يظهر بصرياً بعد العنصر ذي order: 1 */
}
```

> ♿ **تحذير خطير لإمكانية الوصول (Accessibility):** خاصية `order` تغير المظهر **البصري فقط**، بينما يظل ترتيب شجرة الـ DOM والتنقل عبر زر `Tab` في لوحة المفاتيح ثابتاً كما كُتب في HTML! هذا يخلق تشويشاً هائلاً لمستخدمي قارئات الشاشة حيث يقفز مؤشر التركيز في الشاشة بشكل عشوائي ومربك.

---

## 🎯 ملخص وتحدي الدرس

- استخدم `flex-wrap: wrap` لإنشاء بطاقات تتجاوب بسلاسة.
- اعتمد صياغة `flex: <grow> <shrink> <basis>` لاحتراف حساب الأبعاد.
- اضبط `flex-shrink: 0` على الأيقونات والصور لحمايتها من الانضغاط.
- لا تعتمد على `order` كبديل عن كتابة HTML بتسلسل منطقي سليم.

**تحدي الدرس:** أنشئ تخطيطاً يضم شريطاً جانبياً ثابتاً (`flex: 0 0 240px`) وقسماً رئيسياً يتمدد تلقائياً ليملأ كامل الفراغ (`flex: 1 1 auto`)، ويلتف للأسفل في الشاشات الصغيرة.
