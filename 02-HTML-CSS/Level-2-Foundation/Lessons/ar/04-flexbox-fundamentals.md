# 04 - أساسيات نظام التخطيط الانسيابي Flexbox (الحاويات والتدفق أحادي البعد)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/04-flexbox-fundamentals.md) | [العربية 🇸🇦](./04-flexbox-fundamentals.md)

---

## 📌 1. نموذج التخطيط أحادي البعد (One-Dimensional Model)

**Flexbox (Flexible Box Layout - نموذج الصندوق المرن)** هو نظام تخطيط حديث في CSS صُمم لترتيب العناصر ومحاذاتها وتوزيع المساحات بينها في **بُعد واحد في المرة الواحدة**—إما أفقياً كصف (Row) أو رأسياً كعمود (Column). إنه يقضي تماماً على حيل الطفو القديمة وحسابات الهوامش المعقدة.

---

## 🏗️ 2. مفهوم الحاوية (Container) مقابل العناصر (Items)

لتفعيل نظام Flexbox، نكتب الخاصية `display: flex` على العنصر الأب. يتحول هذا الأب فوراً إلى **حاوية مرنة (Flex Container)**، وتتحول كافة العناصر التابعة له مباشرة إلى **عناصر مرنة (Flex Items)**:

```html
<nav class="nav-container">     <!-- الحاوية المرنة Flex Container -->
    <a href="#" class="item">الرئيسية</a>   <!-- عنصر مرن Flex Item -->
    <a href="#" class="item">التوثيق</a>    <!-- عنصر مرن Flex Item -->
    <a href="#" class="item">الدخول</a>     <!-- عنصر مرن Flex Item -->
</nav>
```

```css
.nav-container {
    display: flex; /* تفعيل سياق فليكس بوكس */
}
```

## 🧭 3. المحور الرئيسي (Main Axis) والمحور المتقاطع (Cross Axis)

يعمل أي تخطيط Flexbox وفق محورين متعامدين:

```
                  المحور الرئيسي (flex-direction: row) ────────►
 ┌────────────────────────────────────────────────────────────┐
 │  ┌───────────┐        ┌───────────┐        ┌───────────┐   │  ▲
 │  │  عنصر 1   │        │  عنصر 2   │        │  عنصر 3   │   │  │ المحور
 │  └───────────┘        └───────────┘        └───────────┘   │  │ المتقاطع
 └────────────────────────────────────────────────────────────┘  ▼
```

- **المحور الرئيسي (Main Axis):** يحدده اتجاه `flex-direction`. ونتحكم في محاذاة عناصره عبر `justify-content`.
- **المحور المتقاطع (Cross Axis):** المحور المتعامد عليه (الرأسي في وضع الصف). ونتحكم بمحاذاته عبر `align-items`.

### قيم اتجاه التدفق `flex-direction`:
- `row` (الافتراضي): ترتيب أفقي مع اتجاه القراءة (من اليمين لليسار في RTL).
- `row-reverse`: ترتيب أفقي بالاتجاه المعاكس.
- `column`: ترتيب رأسي كعمود من الأعلى للأسفل.
- `column-reverse`: ترتيب رأسي معكوس من الأسفل للأعلى.

---

## 🎯 4. محاذاة العناصر على المحاور

### أ. محاذاة المحور الرئيسي (`justify-content`):
تتحكم في كيفية توزيع المساحة الفارغة المتبقية:
- `flex-start` (الافتراضي): تجميع العناصر في بداية السطر.
- `flex-end`: تجميع العناصر في نهاية السطر.
- `center`: توسيط العناصر معاً في المنتصف.
- `space-between`: العنصر الأول في أقصى البداية والأخير في أقصى النهاية مع مسافات متساوية بينهما.
- `space-around`: توزيع مسافات متساوية حول كل عنصر.
- `space-evenly`: مسافات متطابقة تماماً بين كل عنصرين وبين أطراف الحاوية.

```css
.header-nav {
    display: flex;
    justify-content: space-between; /* الشعار في أقصى اليمين والروابط في أقصى اليسار */
}
```

### ب. محاذاة المحور المتقاطع (`align-items`):
تتحكم في المحاذاة الرأسية للعناصر:
- `stretch` (الافتراضي): تمدد العناصر لتملأ كامل ارتفاع الحاوية.
- `center`: توسيط العناصر رأسياً في المنتصف تماماً.
- `flex-start`: المحاذاة للأعلى.
- `flex-end`: المحاذاة للأسفل.
- `baseline`: محاذاة خطوط قراءة النصوص عبر كافة العناصر.

---

## 📐 5. التباعد النظيف عبر خاصية `gap`

في CSS الحديثة، لا داعي لحيل `margin-right` واستثناء العنصر الأخير عبر `:last-child`. استخدم ببساطة خاصية `gap`:

```css
.card-group {
    display: flex;
    gap: 1.5rem; /* مسافة متساوية 24px بين كل العناصر تلقائياً */
}
```

---

## ✨ 6. حل معضلة التوسيط الشهيرة في 3 أسطر

تاريخياً، كان التوسيط الأفقي والرأسي الدقيق لعنصر ما في CSS من أصعب التحديات. مع Flexbox أصبح الحل بديهياً:

```css
.hero-banner {
    display: flex;
    justify-content: center; /* توسيط أفقي */
    align-items: center;     /* توسيط رأسي */
    min-height: 100vh;
}
```

---

## 🎯 ملخص وتحدي الدرس

- نظام Flexbox يرتب العناصر في بعد واحد (صف أو عمود).
- خاصية `justify-content` للمحور الرئيسي، و`align-items` للمحور المتقاطع.
- خاصية `gap` تصنع مسافات نقية وثابتة بين العناصر دون حيل الهوامش.

**تحدي الدرس:** أنشئ شريط تنقل متجاوباً يضع شعار الموقع على أحد الطرفين وروابط التنقل على الطرف الآخر باستخدام `display: flex` و `justify-content: space-between` و `align-items: center`.
