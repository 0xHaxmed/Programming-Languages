# 02 - نماذج وحقول HTML5 المتاحة (Forms & Accessible Inputs)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/02-html-forms-and-inputs.md) | [العربية 🇸🇦](./02-html-forms-and-inputs.md)

---

## 📌 1. تشريح نموذج الويب (`<form>`)

النماذج هي قناة التفاعل الرئيسية التي تمكن المستخدم من إدخال البيانات وإرسالها إلى الخوادم (Servers).

```html
<form action="/api/v1/auth/login" method="POST">
    <!-- حقول الإدخال والأزرار -->
</form>
```

### الخصائص الجوهرية للنموذج:
- **`action`:** رابط الوجهة (Endpoint URL) الذي يستقبل بيانات النموذج ويعالجها.
- **`method`:** طريقة طلب HTTP المستخدمة:
  - `GET`: تُدمج الحقول مباشرة في رابط الصفحة (`/search?q=security`). **إياك واستخدام GET لكلمات المرور أو البيانات الحساسة!**
  - `POST`: تُرسل البيانات مشفرة ومضمنة داخل جسم الطلب (HTTP Request Body).
- **`enctype`:** نوع ترميز البيانات المرسلة:
  - `application/x-www-form-urlencoded`: التشفير الافتراضي لأزواج المفتاح والقيمة.
  - `multipart/form-data`: **إلزامي تماماً** عند وجود حقول رفع ملفات (`<input type="file">`).

## 🏷️ 2. عنصر التسمية `<label>` والربط الصريح (Explicit Binding)

> ♿ **قاعدة إمكانية الوصول الذهبية:** كل حقل إدخال **يجب** أن يرتبط بتسمية `<label>` عبر خاصية `for` التي تطابق معرف الحقل `id`.

```html
<!-- كود متاح وقابل للاستخدام: النقر على النص يضع المؤشر داخل الحقل فوراً -->
<label for="user-email">البريد الإلكتروني</label>
<input type="email" id="user-email" name="email" required>
```

### لماذا لا يُعتبر النص التلميحي (Placeholder) بديلاً عن التسمية؟
- خاصية `placeholder="أدخل بريدك"` تختفي بمجرد بدء المستخدم في الكتابة، مما يسبب تشتتاً ذهنياً للمستخدمين ويفشل في معايير سهولة الوصول.

## 🎛️ 3. أنواع حقول الإدخال الحديثة (`<input>`)

توفر HTML5 أنواعاً متخصصة تستدعي لوحات مفاتيح مخصصة في الهواتف الذكية وتقوم بفحص البنية تلقائياً:

| نوع الإدخال | لوحة المفاتيح المستدعاة في الهاتف | السلوك البرمجي التلقائي |
| :--- | :--- | :--- |
| `type="text"` | لوحة المفاتيح النصية العادية | سطر نصي افتراضي |
| `type="email"` | لوحة مفاتيح تحوي `@` ونقطة | فحص بنية البريد الإلكتروني |
| `type="password"` | إخفاء المحارف بنقاط (`•••`) | منع تلصص العيون المجاورة |
| `type="number"` | لوحة الأرقام فقط | قبول `min` و `max` و `step` |
| `type="tel"` | لوحة أرقام الهاتف والاتصال | مناسب لأرقام الهواتف |
| `type="url"` | أزرار سريعة للروابط مثل `.com` و `/` | فحص صحة مسار الرابط |
| `type="date"` | نافذة تقويم منتقي التواريخ | إرجاع التاريخ بصيغة `YYYY-MM-DD` |
| `type="checkbox"` | مربع اختيار ثنائي | خيار منفرد أو اختيارات متعددة |
| `type="radio"` | زر دائري أحادي الاختيار | اختيار وحيد لكل مجموعة تشترك في `name` |
| `type="file"` | نافذة استعراض ملفات الجهاز | دعم قيود الصيغ عبر `accept=".png,.pdf"` |

## 📦 4. الحقول المتقدمة: القوائم، النصوص ومجموعات الحقول

### أ. مجموعات الخيارات عبر `<fieldset>` و `<legend>`:
```html
<fieldset>
    <legend>طريقة استلام إشعارات الأمان</legend>
    <label>
        <input type="radio" name="channel" value="sms" checked> رسالة SMS
    </label>
    <label>
        <input type="radio" name="channel" value="email"> بريد إلكتروني
    </label>
</fieldset>
```

### ب. القائمة المنسدلة (`<select>`):
```html
<label for="role-select">نوع الحساب</label>
<select id="role-select" name="role">
    <option value="" disabled selected>اختر الصلاحية...</option>
    <option value="analyst">محلل أمان سيبراني</option>
    <option value="engineer">مهندس أمان تطبيقات</option>
</select>
```

### ج. النص متعدد الأسطر (`<textarea>`):
```html
<label for="issue-desc">وصف البلاغ الأمني</label>
<textarea id="issue-desc" name="description" rows="4" cols="50"></textarea>
```

---

## 🔘 5. أنواع الأزرار داخل النماذج

- `<button type="submit">`: إرسال بيانات النموذج (السلوك الافتراضي لأي زر داخل نموذج).
- `<button type="button">`: زر عادي لتشغيل أكواد جافا سكريبت (يمنع إرسال النموذج بالخطأ).
- `<button type="reset">`: تفريغ الحقول وإعادتها للقيم الافتراضية.

---

## 🎯 ملخص وتحدي الدرس

- اربط دائماً بين الحقل والتسمية عبر `<label for="...">`.
- حدد أنواع الحقول بدقة لتحسين تجربة المستخدم على الهواتف.
- استخدم `POST` مع `multipart/form-data` عند رفع الملفات.

**تحدي الدرس:** أنشئ نموذج تسجيل حساب متكامل ومتاح يضم: الاسم الكامل، البريد، كلمة المرور، قائمة منسدلة للدور، مربع الموافقة على الشروط، وزر إرسال.
