# 08 - التصميم المتجاوب وفق فلسفة الموبايل أولاً واستعلامات الوسائط (Mobile-First & Media Queries)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/08-mobile-first-responsive-design.md) | [العربية 🇸🇦](./08-mobile-first-responsive-design.md)

---

## 📌 1. النموذج الهندسي لفلسفة "الموبايل أولاً" (Mobile-First Paradigm)

في التطوير القديم ("سطح المكتب أولاً - Desktop-First")، كان المبرمجون يصممون واجهات ضخمة للشاشات الكبيرة ثم يحاولون قصها وتقليصها عبر استعلامات `max-width` لتناسب شاشات الهواتف الصغيرة، مما ينتج أكواداً معقدة وغير فعالة.

تقوم فلسفة **الموبايل أولاً (Mobile-First)** على مبدأ **التحسين التدريجي (Progressive Enhancement)**:
1. تبدأ بكتابة كود الـ CSS الأساسي للهواتف الذكية أولاً (تدفق رأسي بسيط ذو عمود واحد وأقل استهلاك للموارد).
2. تضيف بعد ذلك التخطيطات متعددة الأعمدة والميزات المتقدمة تدريجياً كلما اتسعت الشاشة باستخدام استعلامات `min-width`!

```
 شاشات الهواتف (< 640px)          الأجهزة اللوحية (>= 768px)          الشاشات الكبيرة (>= 1024px)
 ┌──────────────────┐       ┌──────────────────────┐     ┌────────────────────────────┐
 │  [ الترويسة ]    │       │ [الترويسة]           │     │ [الترويسة]                 │
 │  [ التنقل ]      │       ├──────────┬───────────┤     ├───────┬────────────┬───────┤
 │  [ المحتوى ]     │  ──►  │ [المحتوى]│ [الجانبي] │ ──► │[التنقل│ [المحتوى]  │[الجانب│
 │  [ الجانبي ]     │       ├──────────┴───────────┤     ├───────┴────────────┴───────┤
 │  [ التذييل ]     │       │ [التذييل]            │     │ [التذييل]                  │
 └──────────────────┘       └──────────────────────┘     └────────────────────────────┘
```

## 📡 2. قواعد استعلامات الوسائط (`@media`) ونقاط التوقف القياسية

تطبق استعلامات `@media` قواعد التنسيق شرطياً عند تحقق شروط أبعاد الشاشة:

```css
/* ==========================================================================
   1. التنسيق الأساسي: شاشات الهواتف (الافتراضي، دون أي استعلام وسائط!)
   ========================================================================== */
.container {
    width: 100%;
    padding: 1rem;
}

.site-nav {
    display: flex;
    flex-direction: column; /* روابط رأسية متتالية على شاشة الهاتف */
}

/* ==========================================================================
   2. الأجهزة اللوحية واللابتوب الصغير (min-width: 48em / 768px)
   ========================================================================== */
@media (min-width: 48em) {
    .site-nav {
        flex-direction: row; /* روابط أفقية متجاورة على التابلت */
        justify-content: space-between;
    }
}

/* ==========================================================================
   3. الشاشات المكتبية ومحطات العمل (min-width: 64em / 1024px)
   ========================================================================== */
@media (min-width: 64em) {
    .dashboard-layout {
        display: grid;
        grid-template-columns: 260px 1fr;
    }
}
```

### نقاط التوقف العالمية المعتمدة في الصناعة (Standard Breakpoints):
- **`sm` (640px / 40em):** الهواتف الكبيرة والشاشات المحمولة العريضة.
- **`md` (768px / 48em):** الأجهزة اللوحية (iPad/Tablets) في الوضع الرأسي.
- **`lg` (1024px / 64em):** الأجهزة اللوحية في الوضع الأفقي وأجهزة الكمبيوتر المحمول (Laptops).
- **`xl` (1280px / 80em):** الشاشات المكتبية القياسية.
- **`2xl` (1536px / 96em):** شاشات العرض الفائقة 4K والشاشات العريضة جداً.

## 📏 3. النصوص الانسيابية التلقائية عبر دالة `clamp()`

بدلاً من كتابة استعلامات وسائط متعددة لتكبير العناوين، توفر CSS الحديثة دالة الحصر الرياضية `clamp(الحد_الأدنى, القيمة_المثالية, الحد_الأقصى)`:

```css
h1 {
    /* الحد الأدنى: 2rem | القيمة المفضلة: تتوسع مع 5% من عرض الشاشة | الحد الأقصى: 3.75rem */
    font-size: clamp(2rem, 5vw + 1rem, 3.75rem);
}
```
يتمدد الخط بنعومة فائقة مع اتساع الشاشة دون أي قفزات مفاجئة!

## ♿ 4. استعلامات تفضيلات المستخدم وإمكانية الوصول

لا يقتصر التجاوب على حجم الشاشة فقط، بل يمتد لاحترام تفضيلات المستخدم الجسدية والنفسية:

### أ. الوضع الليلي الداكن (`prefers-color-scheme`):
```css
@media (prefers-color-scheme: dark) {
    body {
        background-color: #0f172a;
        color: #f8fafc;
    }
}
```

### ب. مراعاة مرضى الدوار الحركي (`prefers-reduced-motion`):
يعاني بعض المستخدمين من اضطرابات في الأذن الداخلية تسبب لهم دواراً عند رؤية الحركات السريعة. احترم تفضيل نظامهم لإلغاء الحركات:
```css
@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
    }
}
```

## 🎯 ملخص وتحدي الدرس

- اكتب التنسيق الأساسي للموبايل أولاً، ثم تدرج نحو الشاشات الكبيرة باستخدام `min-width`.
- استخدم وحدات `em` أو `rem` في استعلامات الوسائط لدعم تكبير المتصفح بسلاسة.
- اعتمد دالة `clamp()` لتنسيق العناوين الانسيابية.
- ادعم دائماً معيار `prefers-reduced-motion` لاحترام إمكانية الوصول.

**تحدي الدرس:** ابنِ تخطيط بطاقات يعرض عموداً واحداً على الهواتف، ويتحول إلى عمودين على الأجهزة اللوحية (`min-width: 48em`)، وإلى ثلاثة أعمدة على أجهزة الكمبيوتر (`min-width: 64em`)، مع دعم تفعيل الوضع الليلي تلقائياً.
