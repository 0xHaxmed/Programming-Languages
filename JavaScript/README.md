# ⚡ دليل لغة جافا سكريبت | JavaScript Guide

> **بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ**

مرحباً بك في قسم **JavaScript**! جافا سكريبت هي لغة برمجة عالية المستوى (High-level)، مفسرة أو مترجمة في الوقت الحقيقي (JIT-compiled)، ديناميكية، ومتعددة النماذج (Multi-paradigm: Functional & Object-Oriented). وهي العمود الفقري للويب التفاعلي وتعمل على المتصفحات وخوادم الويب (Node.js/Deno/Bun).
