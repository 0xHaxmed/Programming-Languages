# 02 - المتغيرات وأنواع البيانات (Variables & Data Types)

> **بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ**

---

## 📦 ما هو المتغير (Variable)؟

المتغير هو مساحة محجوزة في ذاكرة الجهاز (RAM) باسم محدد لتخزين قيمة معينة (نص، رقم، كائن، إلخ)، والرجوع إليها أو تعديلها لاحقاً في برنامجك.

---

## 🏷️ الإعلان عن المتغيرات (`const` vs `let` vs `var`)

في جافا سكريبت الحديثة (ES6 فما بعدها)، نستخدم طريقتين أساسيتين:

### 1. `const` (Constant - ثابت)
تُستخدم للقيم التي **لن تتغير** بعد تعيينها.
```javascript
const pi = 3.14159;
const appName = "MyCoolApp";

// محاولة إعادة التعيين ستسبب خطأ:
// pi = 3.14; // TypeError: Assignment to constant variable.
```

### 2. `let` (متغير قابل للتغيير)
تُستخدم للقيم التي من المتوقع أن **تتغير قيمتها** أثناء سير البرنامج.
```javascript
let score = 0;
score = 10; // مسموح وطبيعي
```

### 3. `var` (الطريقة القديمة - لا يُنصح بها ❌)
كانت الطريقة المعتمدة قبل عام 2015، ولكنها تسبب مشاكل بسبب غياب مفهوم الـ Block Scope وخاصية الـ Hoisting المربكة.

> [!IMPORTANT]
> **القاعدة الذهبية:**  
> استخدم `const` كخيارك الافتراضي دائماً، وإذا احتجت فعلاً لتغيير القيمة لاحقاً، استبدلها بـ `let`. تجنب استخدام `var` في المشاريع الحديثة تماماً.

## 🗂️ أنواع البيانات في جافا سكريبت (Data Types)

تنقسم أنواع البيانات في JS إلى قسمين رئيسيين:

### أولاً: الأنواع الأولية (Primitive Types)
تُخزن القيمة نفسها مباشرة في الذاكرة (Stack):

| النوع | مثال | الشرح |
| :--- | :--- | :--- |
| **String** | `"أحمد"` أو `'Code'` أو \`مرحباً\` | نصوص وحروف محاطة بعلامات اقتباس |
| **Number** | `42` أو `3.14` أو `-10` | الأعداد الصحيحة والعشرية |
| **Boolean** | `true` أو `false` | قيمة منطقية (صح أو خطأ) |
| **Undefined** | `let x;` | متغير تم تعريفه لكن لم يُعطَ أي قيمة بعد |
| **Null** | `let user = null;` | يمثل عدم وجود قيمة عمداً (قيمة فارغة مقصودة) |
| **BigInt** | `9007199254740991n` | للأرقام الضخمة جداً التي تتجاوز حدود Number |
| **Symbol** | `Symbol("id")` | معرف فريد لا يتكرر |

---

### ثانياً: الأنواع المرجعية (Reference / Object Types)
تُخزن في الذاكرة المخصصة (Heap) ويُشار إليها بواسطة عنوان مرجعي:

```javascript
// 1. الكائن (Object): زوج من المفاتيح والقيم
const user = {
    name: "سارة",
    age: 25,
    isStudent: true
};

// 2. المصفوفة (Array): قائمة مرتبة من العناصر
const programmingLanguages = ["JavaScript", "Python", "C++"];

// 3. الدالة (Function): كتلة من الأوامر القابلة لإعادة الاستخدام
const greet = function() {
    return "السلام عليكم ورحمة الله";
};
```

## 🔍 معرفة نوع المتغير (`typeof`)

يمكنك استخدام المعامل `typeof` لفحص نوع البيانات لأي متغير:

```javascript
console.log(typeof "مرحباً");     // "string"
console.log(typeof 100);          // "number"
console.log(typeof true);         // "boolean"
console.log(typeof undefined);    // "undefined"
console.log(typeof { a: 1 });     // "object"
console.log(typeof [1, 2, 3]);    // "object" (المصفوفات في JS نوع خاص من الكائنات)
console.log(typeof null);         // "object" (خطأ تاريخي شهير في جافا سكريبت)
```

---

## ⚡ النوع الديناميكي (Dynamic Typing)

جافا سكريبت لغة ديناميكية النوع (Dynamically Typed)، أي أنك لست بحاجة لتحديد نوع المتغير مسبقاً، ونوع المتغير يتحدد تلقائياً حسب القيمة المسندة إليه:

```javascript
let data = 10;       // نوعه الآن number
data = "نص جديد";    // أصبح نوعه الآن string بدون أي أخطاء
```

3. احسب عمرك في متغير جديد اسمه `age` بطرح `birthYear` من `currentYear`.
4. اعرض رسالة في الكونسول بصيغة:  
   `"عمري الحالي هو: " + age`
5. اطبع نوع المتغير `age` باستخدام `typeof`.
