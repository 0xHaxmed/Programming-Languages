## 📌 ما هي لغة جافا سكريبت (JavaScript)؟

جافا سكريبت (وتُختصر بـ **JS**) هي واحدة من أشهر لغات البرمجة في العالم وأكثرها انتشاراً. صُممت في الأصل عام 1995 في شركة Netscape لإضافة التفاعلية والحيوية لصفحات الويب الثابتة.

> [!NOTE]
> **ملاحظة تاريخية هامة:**  
> لغة **Java** تختلف تماماً عن **JavaScript**! التشابه في الاسم كان لأسباب تسويقية بحتة في تسعينيات القرن الماضي. كما يُقال في مجتمع المطورين: *"Java هي لـ JavaScript مثل Ham بالنسبة لـ Hamster"*.

---

## 🌐 أين تعمل جافا سكريبت؟

1. **داخل المتصفح (Browser Client-Side):**  
   تحتوي جميع المتصفحات الحديثة على محركات تشغيل (JavaScript Engines)، مثل محرك **V8** في Google Chrome و Microsoft Edge، ومحرك **SpiderMonkey** في Firefox.

2. **خارج المتصفح في الخوادم والأجهزة (Server-Side / Desktop):**  
   بفضل بيئات تشغيل مثل **Node.js** و **Deno** و **Bun**، أصبحت JS لغة عامة الاستخدام تُبنى بها خوادم الويب (Back-end)، تطبيقات سطح المكتب (Electron)، وتطبيقات الهواتف (React Native).

## 🚀 تشغيل أول كود لك (Hello, World!)

توجد 3 طرق رئيسية لتجربة وكتابة كود جافا سكريبت:

### 1. عبر شاشة المتصفح (Developer Tools Console)
- افتح أي صفحة في متصفحك (مثل Chrome).
- اضغط على زر `F12` أو اضغط بالزر الأيمن واختر **Inspect**، ثم انتقل لتبويب **Console**.
- اكتب الكود التالي واضغط `Enter`:

```javascript
console.log("أهلاً بك في عالم جافا سكريبت!");
```

---

### 2. داخل صفحة ويب (HTML)
يمكنك تضمين كود جافا سكريبت داخل ملف HTML باستخدام وسم `<script>`:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>أول تجربة جافا سكريبت</title>
</head>
<body>
    <h1>مرحباً بالعالم!</h1>

    <script>
        console.log("تم تحميل الصفحة وتشغيل الكود بنجاح!");
        // يمكنك إظهار رسالة تنبيه للمستخدم
        alert("أهلاً بك في أول درس جافا سكريبت!");
    </script>
</body>
</html>
```

أو عبر ربط ملف خارجي `script.js`:
```html
<script src="script.js"></script>
```

---

### 3. باستخدام Node.js في الطرفية (Terminal)
إذا كان Node.js مثبتاً على جهازك:
1. أنشئ ملفاً باسم `index.js`.
2. ضع فيه الكود التالي:
   ```javascript
   const message = "مرحباً من بيئة Node.js!";
   console.log(message);
   ```
3. شغّل الملف من موجه الأوامر (Terminal):
   ```bash
   node index.js
   ```

## 📝 قواعد برمجية أساسية (Syntax Basics)

1. **حساسية الأحرف (Case Sensitivity):**  
   جافا سكريبت لغة حساسة لحالة الأحرف؛ المتغير `myVar` يختلف تماماً عن `myvar`.
2. **التعليقات (Comments):**
   ```javascript
   // تعليق سطر واحد (Single-line comment)

   /*
     تعليق متعدد الأسطر
     (Multi-line comment)
   */
   ```
3. **الفاصلة المنقوطة (Semicolons `;`):**  
   في أغلب الحالات، يمتلك محرك JS خاصية الإكمال التلقائي للفواصل (Automatic Semicolon Insertion - ASI)، ولكن يُفضل كتابتها دائماً لتجنب المشاكل النادرة.

## 🎯 تمرين الدرس (Challenge)

1. افتح شاشة الـ Console في متصفحك.
2. اكتب أمراً يطبع اسمك وعمرك في سطر واحد في الكونسول مستخدماً `console.log`.
3. جرب استخدام أمر `console.warn("تنبيه تجريبي")` و `console.error("خطأ تجريبي")` وشاهد كيف تتغير ألوان المخرجات!
