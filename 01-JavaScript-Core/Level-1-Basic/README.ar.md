- **الهدف:** فهم لغة JavaScript بعمق وكتابة كود برمجي سليم ومنطقي من الصفر بمفردك.

## ✅ قائمة التحقق قبل الانتقال للمستوى الثاني
- [ ] تستطيع قراءة وتفسير كل سطر في كود جافا سكريبت بسيط.
- [ ] تستطيع كتابة دوال وتكرار وحسابات بمفردك بدون مراجع خارجية.
- [ ] تدرك الفرق بين `==` و `===` وتعرف لماذا نفضل الصارمة.
- [ ] قمت بتشغيل اختبارات المشروع الختامي وجميعها اجتازت بنجاح (`PASS`).
