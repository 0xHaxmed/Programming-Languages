# تمارين وتطبيقات المستوى الأول (Level 1 Exercises)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./README.md) | [English 🇬🇧](../en/README.md)

مرحباً بك في بنك تمارين المستوى الأول. لحل هذه التمارين، افتح ملف كود محلي (مثلاً `exercises.js`) وطبق كل تمرين بمفردك دون نسخ الكود الجاهز، ثم تحقق من النتيجة في الـ Console!

---

## 🏋️‍♂️ التمرين 1: العمليات والمتغيرات (Variables & Operators)
اكتب دالة باسم `calculateCartTotal(price, quantity, taxPercentage, discountCode)`:
- تحسب السعر الإجمالي للمنتجات ضرب الكمية.
- تضيف نسبة الضريبة المئوية.
- إذا كان `discountCode === "SAVE10"`، تخصم 10% من المجموع.
- ترجع السعر النهائي مقرباً لأقرب رقمين عشريين.

---

## 🏋️‍♂️ التمرين 2: الشروط والتحقق (Conditions & Validation)
اكتب دالة باسم `validateUserAccess(user)` تستقبل كائناً بالشكل التالي:
```javascript
const user = { username: "mohamed", age: 19, isBanned: false };
```
- إذا كان `isBanned === true` ترجع: `"الحساب محظور!"`.
- إذا كان `age < 18` ترجع: `"غير مسموح لمن هم دون 18 عاماً"`.
- إذا كان الاسم فارغاً `username === ""` ترجع: `"اسم المستخدم مطلوب"`.
- إذا اجتازت كل الشروط ترجع: `"مرحباً بك يا [الاسم]"`.

---

## 🏋️‍♂️ التمرين 3: التكرار والمصفوفات (Loops & Arrays)
لديك مصفوفة درجات طلاب:
```javascript
const grades = [65, 88, 42, 95, 73, 50, 38];
```
اكتب كوداً يقوم بالآتي:
1. استخراج الدرجات الناجحة فقط (أكبر من أو تساوي 50) في مصفوفة جديدة اسمها `passingGrades`.
2. حساب متوسط درجات الطلاب الناجحين.
3. إيجاد أعلى درجة وأقل درجة في المصفوفة بدون استخدام `Math.max` و `Math.min` (استخدم حلقة `for`).

---

## 🏋️‍♂️ التمرين 4: معالجة النصوص (String Processing)
اكتب دالة باسم `countVowels(sentence)`:
- تحسب عدد الحروف المتحركة الإنجليزية (`a`, `e`, `i`, `o`, `u`) في أي جملة تمرر لها وتتجاهل الفروق بين الحروف الكبيرة والصغيرة.
- مثال: `countVowels("JavaScript")` يجب أن ترجع `3`.

---

## 🏋️‍♂️ التمرين 5: كائنات ومحاكاة قاعدة بيانات صغيرة (Objects Mini-DB)
أنشئ مصفوفة باسم `inventory` تحتوي على 4 كائنات تمثل منتجات متجر إلكتروني:
```javascript
const inventory = [
    { id: 101, title: "Laptop", stock: 5, price: 15000 },
    { id: 102, title: "Mouse", stock: 0, price: 250 },
    { id: 103, title: "Keyboard", stock: 12, price: 700 },
    { id: 104, title: "Monitor", stock: 3, price: 4200 }
];
```
اكتب دالة باسم `sellItem(id, quantity)`:
- تبحث عن المنتج عبر الـ `id`.
- إذا لم يُعثر على المنتج، ترجع: `"المنتج غير موجود"`.
- إذا كانت الكمية المطلوبة أكبر من المتوفر في `stock`، ترجع: `"الكمية غير متوفرة في المخزن"`.
- إذا كان كل شيء متاحاً، تخصم الكمية من `stock` وترجع رسالة نجاح مع حساب السعر الإجمالي للعملية.
