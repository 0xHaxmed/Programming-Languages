# 10 - هياكل البيانات الأساسية (Arrays & Objects)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./10-basic-data-structures.md) | [English 🇬🇧](../en/10-basic-data-structures.md)

---

## 📚 1. لماذا نحتاج هياكل البيانات؟

المتغيرات العادية تخزن قيمة واحدة فقط (`let age = 25`). ولكن في التطبيقات الواقعية، تحتاج لتخزين قائمة مستخدمين، أو سلة مشتريات، أو بيانات حساب معقدة تحتوي عشرات التفاصيل. هنا يأتي دور **المصفوفات (Arrays)** و **الكائنات (Objects)**.

---

## 🗃️ 2. المصفوفات (Arrays)

المصفوفة هي قائمة مرتبة من العناصر، مفهرسة بأرقام تبدأ دائماً من **الصفر (0)**:

```javascript
const fruits = ["تفاح", "موز", "مانجو"];

// الوصول للعناصر عبر الفهرس (Index):
console.log(fruits[0]); // "تفاح"
console.log(fruits[1]); // "موز"
console.log(fruits.length); // 3 (عدد العناصر الكلي)
```

### أهم العمليات الأساسية على المصفوفات:
```javascript
const tasks = ["قراءة كتاب", "تطبيق تمرين"];

// إضافة عنصر في نهاية المصفوفة:
tasks.push("مراجعة الكود"); 

// حذف العنصر الأخير:
tasks.pop();

// إضافة عنصر في بداية المصفوفة:
tasks.unshift("الاستيقاظ مبكراً");

// حذف العنصر الأول:
tasks.shift();

// التحقق من وجود عنصر:
console.log(tasks.includes("قراءة كتاب")); // true
```

---

## 📦 3. الكائنات (Objects)

الكائن هو هيكل غير مقيد بترتيب رقمي، بل يربط البيانات في صيغة **مفتاح وقيمة (Key-Value Pair)**:

```javascript
const student = {
    firstName: "علي",
    age: 21,
    major: "علوم حاسب",
    gpa: 3.8
};

// 1. الوصول عبر النقطة (Dot Notation) - الأكثر استخداماً:
console.log(student.firstName); // "علي"

// 2. الوصول عبر الأقواس (Bracket Notation) - ممتاز مع المتغيرات والمفاتيح الديناميكية:
console.log(student["major"]); // "علوم حاسب"

let prop = "gpa";
console.log(student[prop]); // 3.8
```

### التعديل والإضافة والحذف في الكائنات:
```javascript
// تعديل قيمة موجودة:
student.age = 22;

// إضافة خاصية جديدة:
student.isGraduated = false;

// حذف خاصية:
delete student.gpa;
```

---

## 🌐 4. الدمج والتداخل (Nesting)

في المشاريع الواقعية، يتم دمج المصفوفات والكائنات معاً لتمثيل البيانات المعقدة (مثل ردود الـ APIs):

```javascript
// مصفوفة تحتوي كائنات (Array of Objects):
const products = [
    { id: 1, name: "لوحة مفاتيح", price: 350 },
    { id: 2, name: "شاشة", price: 2400 },
    { id: 3, name: "سماعة", price: 450 }
];

// المرور على المنتجات وطباعة أسمائها وأسعارها:
for (const product of products) {
    console.log(`المنتج: ${product.name} | السعر: ${product.price} جنيه`);
}
```

---

## 🎯 ملخص وتحدي الدرس

- المصفوفات (`[]`) تخزن قوائم مرتبة تعتمد على الـ Index.
- الكائنات (`{}`) تخزن بيانات وصفية تعتمد على المفاتيح (Keys).
- دمج المصفوفات والكائنات هو الأساس في تبادل البيانات عبر الإنترنت (JSON).

**التحدي:**  
أنشئ مصفوفة باسم `library` تحتوي 3 كتب (كل كتاب عبارة عن Object يحتوي: `title`, `author`, `isRead`).  
قم بكتابة حلقة تكرار تطبع فقط عناوين الكتب التي تم قراءتها (`isRead === true`).
