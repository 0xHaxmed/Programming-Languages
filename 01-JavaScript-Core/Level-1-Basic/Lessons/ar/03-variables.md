# 03 - المتغيرات والفرق بينها (Variables: let, const, var)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./03-variables.md) | [English 🇬🇧](../en/03-variables.md)

---

## 📦 1. ما هو المتغير؟

المتغير في البرمجة هو بمثابة حاوية أو صندوق ذو اسم محدد، يُحجز في ذاكرة الجهاز (RAM) لحفظ قيمة معينة (مثل رقم، نص، أو كائن)، حتى نتمكن من استخدامها وتعديلها أثناء تشغيل البرنامج.

```javascript
let username = "محمد";
console.log(username); // يطبع: محمد
```

## 🏷️ 2. مقارنة شاملة: `const` مقابل `let` مقابل `var`

في جافا سكريبت الحديثة (ES6 فما بعدها)، لدينا ثلاث كلمات مفتاحية لتعريف المتغيرات:

| الميزة | `const` (ثابت) | `let` (متغير حديث) | `var` (قديم - لا يُنصح به) |
| :--- | :---: | :---: | :---: |
| **إمكانية إعادة التعيين (Re-assignment)** | ❌ ممنوع | ✅ نعم | ✅ نعم |
| **إمكانية إعادة التعريف (Re-declaration)** | ❌ ممنوع في نفس النطاق | ❌ ممنوع في نفس النطاق | ✅ مسموح (يسبب مشاكل وأخطاء خفية) |
| **نوع النطاق (Scope)** | Block Scope `{}` | Block Scope `{}` | Function Scope (يتجاهل الكتل `{}`) |
| **منطقة الموت المؤقتة (TDZ)** | ✅ نعم (يمنع الاستخدام قبل السطر) | ✅ نعم (يمنع الاستخدام قبل السطر) | ❌ لا (يتم رفعه كـ `undefined`) |

## 🔍 3. أمثلة وتطبيقات عملية

### أ. استخدام `const` (الخيار الافتراضي دائماً)
يُستخدم للقيم الثابتة التي لن يُعاد تعيينها:
```javascript
const maxLoginAttempts = 3;
const serverUrl = "https://api.example.com";

// محاولة إعادة التعيين ستسبب خطأ:
// maxLoginAttempts = 5; // TypeError: Assignment to constant variable.
```

### ب. استخدام `let` (عند الحاجة للتغيير)
يُستخدم للقيم المتغيرة كعدادات التكرار أو الحالات المتغيرة:
```javascript
let currentScore = 0;
currentScore = currentScore + 10;
console.log(currentScore); // 10
```

### ج. مشاكل `var` ولماذا نتجنبها تماماً ❌
1. **تسرب النطاق (Scope Leak):**
```javascript
if (true) {
    var secret = "123456";
    let safeSecret = "abcdef";
}

console.log(secret); // يطبع "123456"! لأن var تتجاهل حدود الـ if block
// console.log(safeSecret); // ReferenceError: safeSecret is not defined (سلوك آمن)
```

2. **إعادة التعريف بالخطأ دون تحذير:**
```javascript
var balance = 1000;
// كود طويل في منتصف الملف...
var balance = 50; // تم مسح القيمة السابقة بدون أي خطأ أو تنبيه من المترجم!
```

## 📝 4. قواعد تسمية المتغيرات (Naming Rules & Conventions)

1. **الرموز المسموحة:** يمكن أن يحتوي الاسم على حروف إنجليزية، أرقام، علامة الدولار (`$`)، والشرطة السفلية (`_`).
2. **بداية الاسم:** لا يمكن أن يبدأ الاسم برقم (مثال: `1user` ❌ غير مسموح، لكن `user1` ✅ مسموح).
3. **الكلمات المحجوزة (Reserved Words):** لا يمكن استخدام كلمات محجوزة للغة مثل (`let`, `class`, `return`, `function`).
4. **العرف المتبع (Convention):** نستخدم أسلوب سنام الجمل (**camelCase**) للمتغيرات والدوال:
   - `userEmail` ✅
   - `totalItemCount` ✅
   - `isUserLoggedIn` ✅

## 🎯 ملخص وتحدي الدرس

> [!IMPORTANT]
> **قاعدة المطور المحترف:**  
> ابدأ دائماً بـ `const`. إذا اكتشفت لاحقاً أنك بحاجة لتغيير القيمة أثناء تشغيل الكود، حوّلها إلى `let`. لا تستخدم `var` أبداً.

**التحدي:**  
اكتب كوداً يعرف ثابتاً لاسم دولتك، ومتغيراً يحمل مدينتك الحالية، ثم قم بتحديث المدينة لمدينة أخرى واطبع القيم في الكونسول.
