## 📌 1. القواعد الأساسية في بناء الكود (Syntax Rules)

قواعد اللغة (Syntax) هي مجموعة القوانين التي تحدد كيفية كتابة وفهم الكود البرمجي بواسطة محرك جافا سكريبت:

### أ. حساسية حالة الأحرف (Case Sensitivity)
جافا سكريبت تفرق بين الأحرف الكبيرة والصغيرة بدقة.
```javascript
let myVariable = "أحمد";
let myvariable = "سارة";

console.log(myVariable); // أحمد
console.log(myvariable); // سارة
```

### ب. المسافات البيضاء والأسطر الفارغة (Whitespace)
يتجاهل محرك JS المسافات الزائدة بين الكلمات والأسطر، لكن يُفضل دائماً تنسيق الكود ليكون سهل القراءة ونظيفاً.

### ج. الفاصلة المنقوطة (Semicolons `;`)
تُستخدم لإنهاء الأوامر البرمجية. على الرغم من أن محرك JS يحتوي على ميزة الإدراج التلقائي للفاصلة المنقوطة (Automatic Semicolon Insertion - ASI)، إلا أن كتابتها الصريحة بعد كل جملة برمجية تُعد من أفضل الممارسات البرمجية لتفادي أخطاء غير متوقعة.

---

## 💬 2. التعليقات (Comments)

التعليقات هي أسطر يقرؤها المطور ويتجاهلها محرك الجافا سكريبت تماماً أثناء التنفيذ:

```javascript
// هذا تعليق أحادي السطر (Single-line comment)
let score = 100; // يمكن وضع التعليق بجانب الكود

/*
  هذا تعليق متعدد الأسطر
  (Multi-line comment)
  يُستخدم لتوثيق الدوال أو كتابة ملاحظات مفصلة
*/
```

## ⚖️ 3. الفرق بين الجمل والتعابير (Statements vs Expressions)

هذا مفهوم تأسيسي محوري لفهم أسرار لغة جافا سكريبت:

| المفهوم | التعريف | أمثلة |
| :--- | :--- | :--- |
| **التعبير (Expression)** | أي وحدة كود **تُحسب وتُنتج قيمة واحدة** (Produces a Value). | `5 + 3` (تنتج 8)<br>`"مرحباً " + "بالجميع"`<br>`true && false`<br>`typeof 42` |
| **الجملة (Statement)** | وحدة كود برمجية كاملة **تؤدي فعلاً أو إجراءً** (Performs an Action). لا يمكن تمريرها في مكان يتوقع قيمة. | إعلان المتغيرات: `let x = 10;`<br>الجمل الشرطية: `if (x > 5) { ... }`<br>حلقات التكرار: `for (...) { ... }` |

> [!TIP]
> **قاعدة ذهبية للتمييز:**  
> إذا كان بإمكانك طباعة الجزء داخل `console.log(...)` أو وضعه في الجانب الأيمن من علامة `=`، فهو **Expression**!  
> أما إذا تسبب بحدوث خطأ نحوي، فهو **Statement** (مثلاً: `console.log(if (true) { ... })` غير صحيح برمجياً!).

## 🎯 ملخص وتحدي الدرس

- جافا سكريبت حساسة لحالة الأحرف.
- التعليقات تفيد في توثيق الكود وتسهيل مراجعته لاحقاً.
- التعبير (Expression) يُنتج قيمة، والجملة (Statement) تنفذ إجراءً وتوجيهاً للبرنامج.

**التحدي:** حدد أياً من الأسطر التالية يُعتبر Expression وأيها يُعتبر Statement:
1. `let greeting = "Hello";`
2. `10 * 4`
3. `if (true) { console.log("Yes"); }`
4. `"JS" === "JS"`
