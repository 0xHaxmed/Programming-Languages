# 04 - أنواع البيانات في جافا سكريبت (Data Types)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./04-data-types.md) | [English 🇬🇧](../en/04-data-types.md)

---

## 🗂️ 1. نظرة عامة على أنواع البيانات

جافا سكريبت لغة **ديناميكية النوع (Dynamically Typed)**، بمعنى أنك لا تحتاج لتحديد نوع المتغير مسبقاً، ونوع المتغير يتحدد تلقائياً حسب القيمة التي يحملها:

```javascript
let myData = 42;       // نوعه الآن Number
myData = "نص جديد";    // تحول تلقائياً إلى String
```

تنقسم أنواع البيانات في JS إلى قسمين أساسيين:
1. **الأنواع الأولية (Primitive Types)**
2. **الأنواع المرجعية (Reference / Object Types)**

---

## 🧱 2. الأنواع الأولية (Primitive Types)

تُخزن قيمتها مباشرة في ذاكرة الـ Stack، وهي غير قابلة للتغيير الداخلي (Immutable):

| النوع | مثال | الشرح |
| :--- | :--- | :--- |
| **String** | `"مرحباً"`, `'JS'`, \`قيمة: ${x}\` | سلاسل نصية. تُدعم النصوص بالقوالب (Template Literals) باستخدام (\`\`). |
| **Number** | `100`, `3.14`, `-5`, `Infinity`, `NaN` | يمثل الأعداد الصحيحة والعشرية معاً. (`NaN` تعني Not-a-Number وتحدث عند عملية حسابية خاطئة). |
| **Boolean** | `true` أو `false` | القيم المنطقية (صح أو خطأ) المستخدمة في الشروط. |
| **Undefined** | `let a;` | متغير تم الإعلان عنه لكن لم تُسند له أي قيمة بعد (القيمة الافتراضية). |
| **Null** | `let user = null;` | غياب متعمد ومقصود للقيمة (فارغ عمداً). |
| **BigInt** | `9007199254740991n` | أرقام صحيحة ضخمة جداً تتجاوز حد `Number.MAX_SAFE_INTEGER`. |
| **Symbol** | `Symbol("id")` | قيمة أولية فريدة تماماً لا يمكن تكرارها، تُستخدم كمفاتيح للكائنات. |

---

## 📦 3. الأنواع المرجعية (Reference Types / Objects)

تُخزن في ذاكرة الـ Heap، والمتغير يحمل فقط مؤشراً مرجعياً (Reference/Pointer) لمكانها في الذاكرة:

### أ. الكائن (Object)
تجمع مجموعة من الخصائص في صيغة (مفتاح: قيمة):
```javascript
const user = {
    name: "عمر",
    age: 28,
    isDeveloper: true
};
console.log(user.name); // عمر
```

### ب. المصفوفة (Array)
قائمة مرتبة من العناصر المفهرسة بأرقام تبدأ من الصفر:
```javascript
const fruits = ["تفاح", "موز", "برتقال"];
console.log(fruits[0]); // تفاح
```

### ج. الدالة (Function)
في JS الدوال تُعامل كـ "First-Class Citizens" وتُعتبر نوعاً خاصاً من الكائنات:
```javascript
function greet() {
    return "السلام عليكم!";
}
```

---

## 🔍 4. فحص الأنواع باستخدام `typeof`

المعامل `typeof` يُرجع نصاً يوضح نوع البيانات:

```javascript
typeof "أحمد";        // "string"
typeof 99.9;          // "number"
typeof true;          // "boolean"
typeof undefined;     // "undefined"
typeof { id: 1 };     // "object"
typeof [1, 2, 3];     // "object" (المصفوفات في JS هي كائنات)
typeof function(){};  // "function"
```

> [!WARNING]
> **الخطأ التاريخي الشهير في جافا سكريبت:**  
> ```javascript
> typeof null; // "object"
> ```  
> هذا خطأ برمجي في تصميم المحرك الأول عام 1995 ولم يتم تصحيحه حتى اليوم للحفاظ على توافق المواقع القديمة (Backward Compatibility). تذكر دائماً: `null` هو نوع أولي (Primitive) وليس كائناً!

---

## 🎯 ملخص وتحدي الدرس

- هناك 7 أنواع أولية في JS أهمها: String, Number, Boolean, null, undefined.
- الكائنات والمصفوفات والدوال هي أنواع مرجعية.
- `typeof` أداة أساسية لمعاينة الأنواع أثناء التطوير والتصحيح.

**التحدي:**  
عرّف متغيراً باسم `itemPrice` بقيمة عددية، ومتغيراً باسم `discount` بقيمة نصية `"10"`. استخدم `typeof` لطباعة نوع كل منهما، ثم أجب: ماذا تتوقع أن يحدث لو قمت بجمعهما معاً؟ سنكتشف هذا في درس التحويل القادم!
