# 08 - حلقات التكرار (Loops: for, while, do...while)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./08-loops.md) | [English 🇬🇧](../en/08-loops.md)

---

## 🔁 1. ما هي حلقات التكرار؟

حلقات التكرار (Loops) تسمح لك بتكرار تنفيذ كتلة كود معينة عدة مرات طالما أن هناك شرطاً معيناً لا يزال صحيحاً (`true`). بدلاً من كتابة الكود 100 مرة يدوياً، تجعل الحلقة تكرره لك في أسطر معدودة.

---

## 🔄 2. حلقة `for` الكلاسيكية

تُستخدم عندما تعرف **عدد مرات التكرار** مسبقاً:

```
for (التهيئة المبدئية; شرط الاستمرار; خطوة التحديث)
```

```javascript
for (let i = 1; i <= 5; i++) {
    console.log("الرقم الحالي هو: " + i);
}
// المخرجات:
// الرقم الحالي هو: 1
// الرقم الحالي هو: 2
// الرقم الحالي هو: 3
// الرقم الحالي هو: 4
// الرقم الحالي هو: 5
```

---

## ⏳ 3. حلقة `while`

تُستخدم عندما **لا تعرف بدقة كم مرة سيتكرر الكود**، ولكنك تريد أن يستمر طالما أن هناك شرطاً يتحقق:

```javascript
let fuel = 5;

while (fuel > 0) {
    console.log(`الوقود المتبقي: ${fuel} لتر`);
    fuel--; // خطوة هامة لإنقاص الوقود لتجنب حلقة لا نهائية!
}

console.log("نفد الوقود وتوقفت السيارة.");
```

---

## 🚦 4. حلقة `do...while`

تشبه `while`، ولكن الفارق الجوهري أنها **تنفذ الكود مرة واحدة على الأقل** قبل أن تفحص الشرط:

```javascript
let count = 10;

do {
    console.log("تم التنفيذ مرة واحدة على الأقل!");
    count++;
} while (count < 5); // الشرط غير متحقق من البداية، ومع ذلك نُفذت الكتلة مرة
```

---

## 🛑 5. التحكم في سير الحلقة: `break` و `continue`

- **`break`:** تُوقف الحلقة بالكامل وتخرج منها فوراً.
- **`continue`:** تتخطى الدورة الحالية فقط وتنتقل مباشرة للدورة التالية.

```javascript
for (let i = 1; i <= 10; i++) {
    if (i === 3) {
        continue; // تخطى الرقم 3 ولا تطبعه
    }
    if (i === 7) {
        break; // أوقف الحلقة بالكامل عند الوصول لـ 7
    }
    console.log(i); // سيطبع: 1, 2, 4, 5, 6
}
```

---

## 🌟 6. حلقات التكرار الحديثة: `for...of` و `for...in`

### أ. `for...of` (للمصفوفات والنصوص)
أسهل وأوضح طريقة للمرور على عناصر المصفوفات:
```javascript
const colors = ["أحمر", "أخضر", "أزرق"];

for (const color of colors) {
    console.log("اللون: " + color);
}
```

### ب. `for...in` (لخصائص الكائنات)
تُستخدم للمرور على مفاتيح الكائنات (Object Keys):
```javascript
const user = { name: "خالد", age: 30, city: "القاهرة" };

for (const key in user) {
    console.log(`${key}: ${user[key]}`);
}
```

---

## 🎯 ملخص وتحدي الدرس

- `for` مناسبة عندما يكون عدد المرات معروفاً.
- `while` مناسبة عندما يرتبط التكرار بشرط قد ينتهي في أي وقت.
- `break` تنهي الحلقة، و `continue` تقفز للدورة التالية.
- `for...of` هي الخيار الأفضل لقراءة عناصر المصفوفات.

**التحدي:**  
اكتب حلقة `for` تطبع الأرقام الزوجية فقط من 1 إلى 20. (تلميح: استخدم باقي القسمة `% 2 === 0` أو `continue`).
