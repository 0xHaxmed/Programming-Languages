## 📌 1. يعني إيه JavaScript؟

**جافا سكريبت (JavaScript)** هي لغة برمجة عالية المستوى (High-level)، ديناميكية (Dynamic)، ومفسرة (Interpreted / JIT-compiled).  
صُممت في الأصل عام 1995 بواسطة "بريندان آيك" (Brendan Eich) لإضافة التفاعلية والحيوية لصفحات الويب التي كانت قديماً مجرد نصوص وصور ثابتة.

> [!NOTE]
> **تنبيه هام للمبتدئين:**  
> لغة **Java** تختلف كلياً عن **JavaScript** في البنية، والتصميم، والغرض. التشابه في الاسم كان لأسباب تسويقية بحتة في تسعينيات القرن الماضي.

## 🏗️ 2. علاقة JavaScript بـ HTML و CSS

تُبنى أي صفحة ويب تفاعلية على ثلاث ركائز أساسية:

1. **HTML (الهيكل والعظام):**  
   تحدد المحتوى الأساسي للصفحة (عناوين، فقرات، أزرار، صور، حقول إدخال).
2. **CSS (المظهر والجماليات):**  
   تحدد الألوان، الخطوط، التنسيقات، والتصميم المتجاوب مع الشاشات المختلفة.
3. **JavaScript (العقل والحركة والتفاعل):**  
   تجعل الصفحة تستجيب للمستخدم (الضغط على الأزرار، إرسال البيانات دون إعادة تحميل الصفحة، التحقق من المدخلات، جلب البيانات في الخلفية).

```
   [ HTML ]      +      [ CSS ]      +      [ JavaScript ]
(هيكل الصفحة)         (الشكل والألوان)         (التفاعل والمنطق)
```

## ⚙️ 3. أين تعمل JavaScript؟

### أ. داخل المتصفح (Client-Side)
جميع المتصفحات الحديثة (Chrome, Firefox, Safari, Edge) تمتلك بداخلها **محرك جافا سكريبت (JS Engine)** يقوم بقراءة الكود وتحويله إلى كود تفهمه الآلة:
- **V8:** في متصفح Google Chrome و Microsoft Edge.
- **SpiderMonkey:** في متصفح Firefox.
- **JavaScriptCore (Nitro):** في متصفح Safari.

### ب. خارج المتصفح (Server-Side / Desktop)
من خلال بيئات تشغيل مثل **Node.js** و **Deno** و **Bun**، خرجت جافا سكريبت من حدود المتصفح، وأصبح بالإمكان استخدامها لبناء:
- خوادم ومواقع الويب (Back-end APIs).
- برامج سطح المكتب (باستخدام Electron مثل VS Code نفسه!).
- تطبيقات الهواتف الذكية وأدوات الأتمتة (Automation Scripts).

## 🚀 4. تشغيل أول كود لك (Hands-on)

### الطريقة 1: متصفحك مباشرة (Console)
1. افتح أي تبويب في المتصفح.
2. اضغط على `F12` أو اضغط بالزر الأيمن واختر **Inspect**، ثم انتقل لتبويب **Console**.
3. اكتب الكود التالي واضغط `Enter`:

```javascript
console.log("أهلاً بك في أول خطوة في عالم JavaScript!");
```

### الطريقة 2: ملف HTML مع كود JS
أنشئ ملفاً بسيطاً باسم `index.html`:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>أول تجربة JS</title>
</head>
<body>
    <h1>مرحباً بالعالم!</h1>

    <script>
        console.log("تم تشغيل الكود بنجاح من داخل صفحة الويب!");
    </script>
</body>
</html>
```

## 🎯 ملخص وتحدي الدرس

- جافا سكريبت هي لغة التفاعل والمنطق للويب وخارجه.
- HTML يعطي الهيكل، CSS يعطي التنسيق، و JS تعطي السلوك.
- محرك المتصفح (مثل V8) هو الذي ينفذ الكود.

**التحدي:** افتح الـ Console في متصفحك واكتب أمراً يطبع اسمك ورسالة ترحيبية، ثم جرب استخدام دالة `alert("مرحباً!")`.
