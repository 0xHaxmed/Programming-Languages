# 07 - الجمل الشرطية والتحكم في المسار (Conditions: if, switch & Truthy/Falsy)

> 🌐 **اللغة / Language:** [العربية 🇸🇦](./07-conditions.md) | [English 🇬🇧](../en/07-conditions.md)

## 🚦 1. ما هي الجمل الشرطية؟

الجمل الشرطية تمكنك من اتخاذ قرارات داخل البرنامج؛ أي تنفيذ كتلة كود معينة فقط إذا تحقق شرط معين، أو الانتقال لمسار بديل إذا لم يتحقق الشرط.

---

## 🔀 2. استخدام `if`, `else if`, و `else`

```javascript
let examScore = 85;

if (examScore >= 90) {
    console.log("التقدير: ممتاز (A)");
} else if (examScore >= 80) {
    console.log("التقدير: جيد جداً (B)");
} else if (examScore >= 65) {
    console.log("التقدير: جيد (C)");
} else if (examScore >= 50) {
    console.log("التقدير: مقبول (D)");
} else {
    console.log("للأسف، راسب (F)");
}
```

## 🎭 3. مفهوم القيم الحقيقية والمزيفة (Truthy & Falsy Values)

في جافا سكريبت، أي قيمة يمكنك وضعها داخل شرط الـ `if` تُحوَّل تلقائياً إلى `true` أو `false`.

### القيم الـ 8 التي تُعتبر دائماً Falsy ❌:
1. `false`
2. `0` و `-0`
3. `0n` (BigInt zero)
4. `""` أو `''` (النص الفارغ)
5. `null`
6. `undefined`
7. `NaN`

> [!IMPORTANT]
> **كل ما عدا هذه القيم الثمانية يُعتبر Truthy ✅!**  
> يشمل ذلك:
> - المصفوفة الفارغة `[]` (تُعتبر Truthy!)
> - الكائن الفارغ `{}` (يُعتبر Truthy!)
> - النص الذي يحتوي مسافة أو رقم `"0"` أو `"false"` (تُعتبر نصوصاً غير فارغة لذا هي Truthy!).

```javascript
let userInput = ""; // نص فارغ (Falsy)

if (userInput) {
    console.log("المستخدم أدخل بيانات");
} else {
    console.log("حقل الإدخال فارغ!"); // سيطبع هذا
}
```

## ⚡ 4. المعامل الثلاثي (Ternary Operator)

هو طريقة مختصرة وأنيقة لكتابة `if / else` البسيطة في سطر واحد:

```
الشرط ? النتيجة إذا تحقق : النتيجة إذا لم يتحقق
```

```javascript
let age = 20;
let accessMessage = age >= 18 ? "مرحباً بك، بالغ" : "عذراً، غير مسموح للقاصرين";
console.log(accessMessage); // مرحباً بك، بالغ
```

## 🎛️ 5. جملة `switch / case`

تُستخدم عندما ترغب في مقارنة متغير واحد مع قائمة محددة من الاحتمالات الثابتة:

```javascript
let role = "admin";

switch (role) {
    case "admin":
        console.log("صلاحيات كاملة للوحة التحكم");
        break; // يمنع النزول لتنفيذ الحالات التالية (Fallthrough)
    case "editor":
        console.log("صلاحيات تعديل المحتوى فقط");
        break;
    case "subscriber":
        console.log("صلاحيات قراءة المحتوى");
        break;
    default:
        console.log("حساب غير مسجل أو غير معروف");
}
```

> [!WARNING]
> لا تنسَ كتابة كلمة `break` بعد كل `case`! نسيانها سيجعل المحرك ينفذ الحالات التالية حتى لو لم يتحقق شرطها.

## 🎯 ملخص وتحدي الدرس

- استخدم `if/else` للشروط المنطقية والمقارنات المركبة.
- احفظ القيم الـ 8 الـ Falsy لتفهم سلوك التحقق من البيانات.
- استخدم الـ Ternary Operator للتعبير السريع والـ `switch` للخيارات المحددة.

**التحدي:**  
اكتب برنامجاً يفحص متغيراً باسم `orderTotal`.  
- إذا كان الإجمالي أكثر من 200 جنيه، يحصل المستخدم على "شحن مجاني".
- إذا كان بين 100 و 200، تكون رسوم الشحن "20 جنيه".
- إذا كان أقل من 100، تكون رسوم الشحن "40 جنيه".
