### 🎯 المهارات التي ستخرج بها من هذا المستوى
- [x] قراءة كود JavaScript بسيط وفهم ماذا يفعل كل سطر بدقة.
- [x] كتابة Functions و Conditions و Loops بمفردك ومنطقك الخاص.
- [x] التعامل مع Arrays و Objects بسلاسة وفهم الذاكرة دون نسخ كود جاهز.
- [x] توقع مخرجات الكود ومعرفة أسباب الأخطاء وإصلاحها.
- [x] فهم أنواع البيانات وكيف تتغير تلقائياً أثناء تنفيذ البرنامج.
