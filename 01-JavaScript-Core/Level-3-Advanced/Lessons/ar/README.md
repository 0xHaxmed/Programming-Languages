| **12** | `12-modern-bundling-sourcemaps.md` | التعامل مع الأكواد المضغوطة (Minified)، أدوات الحزم (Bundlers)، واستخدام ملفات Source Maps. |
| **13** | `13-security-aware-coding.md` | البرمجة الواعية أمنياً: التعامل الآمن مع نصوص وخصائص الـ DOM ومراجعة الـ APIs الحساسة (`eval`, `postMessage`). |
