# 02 - الكلمة المفتاحية 'this' وقواعد الارتباط الأربعة (The 'this' Keyword)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/02-the-this-keyword.md) | [العربية 🇸🇦](./02-the-this-keyword.md)

---

## 🎯 1. نظرة عامة وأهداف التعلم (Overview & Learning Objectives)

تعد الكلمة المفتاحية `this` واحدة من أكثر المفاهيم التي يساء فهمها في لغة جافا سكريبت. على عكس نطاق المتغيرات (Scope) الذي يتحدد **معجمياً (Lexically)** أثناء كتابة الكود المصدري، فإن ارتباط `this` يتحدد **ديناميكياً وقت التشغيل (Runtime)** بناءً على **موضع وطريقة الاستدعاء (Call-Site)**.

بنهاية هذا الدرس، ستتقن:
1. الطبيعة الديناميكية لـ `this` وكيف تختلف جذرياً عن النطاق المعجمي.
2. **قواعد الارتباط الأربعة لكائن `this`** مرتبة حسب الأولوية الصارمة.
3. تشخيص وحل مشكلة **فقدان سياق `this`** الشائعة عند تمرير الدوال كـ Callbacks.
4. إجبار الدوال على سياق تنفيذ محدد باستخدام `.call()` و `.apply()` و `.bind()`.
5. لماذا لا تمتلك **الدوال السهمية (Arrow Functions)** كائن `this` خاصاً بها وكيف ترثه معجمياً.
6. التخلص من الحلول الترقيعية القديمة مثل `var self = this`.

## ⚖️ 2. قواعد الارتباط الأربعة لكائن 'this' (مرتبة حسب الأولوية)

عندما تُستدعى أي دالة، يحدد محرك جافا سكريبت قيمة `this` عبر فحص هذه القواعد الأربع بترتيب أسبقية صارم:

```
الأولوية القصوى (HIGHEST PRECEDENCE):
  1. ارتباط new             ---> هل تم استدعاء الدالة كمنشئ باستخدام new؟
  2. الارتباط الصريح        ---> هل تم استدعاء الدالة عبر call() أو apply() أو bind()؟
  3. الارتباط الضمني        ---> هل استُدعيت الدالة كخاصية تابعة لكائن (obj.method())؟
  4. الارتباط الافتراضي     ---> استدعاء الدالة منفردة ومجردة (fn()).
الأولوية الأدنى (LOWEST PRECEDENCE)
```

---

### القاعدة 1: الارتباط الافتراضي (Default Binding)
عند استدعاء دالة عادية منفردة دون أي كائن حاوٍ:

```javascript
function showContext() {
  console.log(this);
}

// في الوضع العادي (Non-Strict): يشير للكائن العام (window في المتصفح):
showContext(); // Window

// في الوضع الصارم ('use strict'): تكون قيمته بأمان undefined لمنع الأخطاء:
function showStrict() {
  'use strict';
  console.log(this);
}
showStrict(); // undefined
```

---

### القاعدة 2: الارتباط الضمني (Implicit Binding)
عندما تُستدعى الدالة كطريقة (Method) تابعة لكائن يسبقها نقطة (`.`):

```javascript
const user = {
  name: 'أحمد',
  greet() {
    console.log(`مرحباً، أنا ${this.name}`);
  }
};

user.greet(); // "مرحباً، أنا أحمد" (موضع الاستدعاء يسبقه الكائن user مباشرة)
```

#### 💥 فخ فقدان سياق `this` الشهير:
عند تمرير دالة تابعة لكائن كـ Callback لدالة أخرى، يُفقد الارتباط الضمني فوراً:

```javascript
// ❌ خطأ برمجي شائع: تمرير الدالة كـ Callback
setTimeout(user.greet, 1000); 
// النتيجة بعد ثانية: "مرحباً، أنا undefined"!
// السبب: تقوم setTimeout باستدعاء الدالة greet() منفردة ومجردة، فتنطبق عليها القاعدة الافتراضية!
```

---

### القاعدة 3: الارتباط الصريح (Explicit Binding: `call`, `apply`, `bind`)
لإجبار دالة على العمل بسياق كائن محدد، نستخدم دوال النموذج الموروثة من `Function.prototype`:

```javascript
function printProfile(role, country) {
  console.log(`${this.name} | الوظيفة: ${role} | الدولة: ${country}`);
}

const employee = { name: 'سارة' };

// 1. .call(): تستدعي الدالة فوراً مع تمرير المعاملات مفصولة بفواصل:
printProfile.call(employee, 'مهندس أمن سيبراني', 'مصر');

// 2. .apply(): تستدعي الدالة فوراً مع تمرير المعاملات داخل مصفوفة Array:
printProfile.apply(employee, ['مدير مشاريع', 'السعودية']);

// 3. .bind(): لا تستدعي الدالة فوراً، بل تُرجع دالة جديدة تماماً مربوطة بهذا الكائن للأبد:
const boundProfile = printProfile.bind(employee, 'محلل ثغرات');
boundProfile('الإمارات'); // سارة | الوظيفة: محلل ثغرات | الدولة: الإمارات
```

---

### القاعدة 4: ارتباط `new` (Constructor Invocation)
عند استدعاء دالة مسبوقة بالكلمة المفتاحية `new`:
1. يُنشأ كائن فارغ جديد تماماً في الـ Heap: `{}`.
2. يتم ربط الكائن الجديد بنموذج الدالة الأولي (Prototype).
3. **يتم ربط `this` بهذا الكائن الجديد فوراً** أثناء تنفيذ الدالة.
4. إذا لم تُرجع الدالة كائناً صريحاً، يتم إرجاع `this` تلقائياً.

```javascript
function UserProfile(name, email) {
  // تشير 'this' هنا إلى الكائن الفارغ الجديد:
  this.name = name;
  this.email = email;
}

const user1 = new UserProfile('كريم', 'karim@example.com');
console.log(user1.name); // 'كريم'
```

## 🏹 3. الاستثناء الحديث: الدوال السهمية (Arrow Functions)

الدوال السهمية **لا تمتلك كائن `this` خاصاً بها إطلاقاً**!  
بدلاً من ذلك، ترث الدوال السهمية قيمة `this` **معجمياً (Lexically)** من النطاق الخارجي الذي كُتبت بداخله:

```javascript
const company = {
  name: 'شركة الأمن السيبراني',
  employees: ['علي', 'عمر'],
  printRoster() {
    // ترث الدالة السهمية قيمة this من دالة printRoster (والتي تشير لكائن company):
    this.employees.forEach(emp => {
      console.log(`${emp} يعمل في ${this.name}`);
    });
  }
};

company.printRoster();
// "علي يعمل في شركة الأمن السيبراني"
// "عمر يعمل في شركة الأمن السيبراني"
```

> [!NOTE]
> نظراً لأن الدوال السهمية ترث `this` معجمياً وقت كتابة الكود، فإن محاولة استخدام `.bind()` أو `.call()` أو `.apply()` عليها **لن يغير قيمة `this` الخاصة بها نهائياً**!

## 🧼 4. مقارنة الكود النظيف (Clean Code: Good vs Bad)

```javascript
// ❌ كود قديم وسيئ: تخزين مرجع this يدوياً في متغير مؤقت (حيلة قديمة من عام 2012)
function Cart() {
  var self = this; // أسلوب قديم ومنبوذ
  setTimeout(function() {
    console.log(self.items);
  }, 500);
}

// ✅ كود ممتاز: استخدام دالة سهمية حديثة تحافظ على السياق المعجمي بنظافة
function Cart() {
  setTimeout(() => {
    console.log(this.items); // ترث this تلقائياً وبأمان
  }, 500);
}

// ❌ كود سيئ: استخدام دوال سهمية كطرق لكائنات (يكسر الارتباط الضمني!)
const counter = {
  count: 0,
  increment: () => {
    this.count++; // تشير this إلى window العام وليس لكائن counter!
  }
};

// ✅ كود ممتاز: استخدام صياغة الدوال العادية لخصائص الكائنات
const counter = {
  count: 0,
  increment() {
    this.count++; // تشير this بشكل صحيح لكائن counter
  }
};
```

## 📝 5. الخلاصة والدرس التالي
- تتحدد قيمة `this` **وقت التشغيل بناءً على موضع الاستدعاء (Call-Site)**، وليس وقت كتابة الكود (باستثناء الدوال السهمية).
- أولوية القواعد: **`new` > الصريح (`bind/call`) > الضمني (`obj.fn()`) > الافتراضي (`undefined`/`window`)**.
- استخدم **الدوال السهمية** أو دالة **`bind()`** لمنع فقدان سياق `this` في الـ Callbacks.
- **لا تستخدم الدوال السهمية** كطرق مباشرة للكائنات إذا كانت تحتاج للوصول لخصائص الكائن.
- في الدرس التالي، سنشرح صميم نموذج الكائنات في جافا سكريبت: **النماذج الأولية وسلسلة الوراثة (Prototypes, Prototype Chains & Inheritance)**.
