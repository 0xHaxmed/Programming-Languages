## 🧪 معمل التطبيقات العملية للمستوى الثاني

يحتوي هذا المعمل على تدريبات تفاعلية تركز على بناء وتعديل عناصر صفحة الويب والتعامل مع الشبكة وتصحيح الأخطاء:

### 1. معمل شجرة الـ DOM وتعديل العناصر (DOM Lab)
- بناء قائمة مهام تفاعلية (Interactive To-Do List) تتيح إضافة عنصر، تعليمه كمكتمل، وحذفه مع تحديث العداد ديناميكياً.
- فهم الفرق بين `textContent` و `innerHTML` ولماذا يُعتبر استخدام `innerHTML` مع مدخلات المستخدم ثغرة أمنية (DOM XSS).

### 2. معمل تفويض الأحداث (Event Delegation Lab)
- إدارة جدول بيانات يحتوي على 100 زر حذف باستخدام مستمع أحداث واحد فقط (`addEventListener`) على العنصر الأب بدلاً من وضع 100 مستمع.

### 3. معمل النماذج وتتبع البيانات (Forms & Validation Lab)
- نموذج تسجيل دخول يتحقق من قوة كلمة المرور وصحة البريد الإلكتروني في الوقت الفعلي أثناء كتابة المستخدم (`input event`).
- منع إرسال الصفحة الافتراضي باستخدام `event.preventDefault()`.

### 4. معمل فحص الشبكة واستكشاف DevTools (DevTools & Network Lab)
- فتح تبويب Network في Chrome DevTools وفحص طلبات الـ HTTP والـ Status Codes (200, 404, 500).
- وضع Breakpoint في كود JavaScript وتتبع قيم المتغيرات خطوة بخطوة (Step Over, Step Into).
