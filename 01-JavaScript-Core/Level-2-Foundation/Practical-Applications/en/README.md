## 🧪 Level 2 Applied Labs

Hands-on browser engineering labs bridging static code logic with interactive runtime DOM manipulation, network diagnostics, and event architectures:

### 1. DOM Tree Manipulation & Security Lab
- Construct a dynamic Task Management UI supporting real-time item creation, state toggling, and deletion.
- Delineate security boundaries between safe node text insertion (`textContent`) vs hazardous injection vectors (`innerHTML` and DOM-based Cross-Site Scripting).

### 2. Event Delegation & Lifecycle Lab
- Implement high-performance event delegation managing large data matrices by attaching a single event listener to an ancestor node instead of hundreds of child handlers.
- Trace capturing and bubbling event propagation dynamics.

### 3. Forms & State Verification Lab
- Implement real-time input validation on client forms using input events.
- Intercept default browser navigation via `event.preventDefault()`.

### 4. DevTools Forensics & Network Interception Lab
- Inspect HTTP request/response payloads, headers, and status codes (200, 301, 401, 500) via the DevTools Network panel.
- Pause execution mid-flight using conditional breakpoints and inspect scoped memory allocations via the Sources panel.
