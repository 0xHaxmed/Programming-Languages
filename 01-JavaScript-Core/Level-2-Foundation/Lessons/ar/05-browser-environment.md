# 05 - بيئة المتصفح: كائن window ونموذج BOM وواجهات Web APIs

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/05-browser-environment.md) | [العربية 🇸🇦](./05-browser-environment.md)

---

## 🎯 1. نظرة عامة وأهداف التعلم (Overview & Learning Objectives)

عندما تعمل لغة جافا سكريبت داخل متصفحات الويب (مثل Chrome أو Firefox أو Safari)، فإنها تعمل داخل **بيئة استضافة (Host Environment)**. إن محرك جافا سكريبت الأساسي (مثل محرك V8) يفهم فقط قواعد اللغة والمتغيرات والكائنات والدوال. أما كل ما يتعلق بعرض عناصر HTML، وإجراء اتصالات الشبكة، وإدارة المؤقتات، والتعامل مع الشاشة، فهو مقدم من **واجهات برمجة المتصفح (Web APIs)**.

بنهاية هذا الدرس، ستتقن:
1. التمييز المعماري بين **محرك جافا سكريبت** وبيئة **استضافة المتصفح (Web APIs)**.
2. وظيفة ومكانة **الكائن العام `window`** والمعيار العالمي `globalThis`.
3. استكشاف **نموذج كائن المتصفح (BOM)**: كائنات `navigator`، `location`، `history`، و `screen`.
4. الآثار الهندسية والأمنية للتنقل عبر الروابط باستخدام `location` مقابل `history`.
5. لماذا تتجنب التطبيقات الاحترافية الحديثة مربعات الحوار المعطلة للشاشة (`alert`, `confirm`, `prompt`).
6. تطبيق مبدأ **فحص الميزات (Feature Detection)** كبديل آمن لفحص نص المتصفح (User-Agent Sniffing).

## 🏛️ 2. المخطط المعماري: المحرك مقابل واجهات المتصفح

```
+-----------------------------------------------------------------------------------+
|                              بيئة تشغيل المتصفح (BROWSER RUNTIME)                  |
+-----------------------------------------------------------------------------------+
|  محرك جافا سكريبت (V8 ENGINE)        |  واجهات المتصفح المدمجة (WEB APIs من المتصفح)   |
|  - مكدس الاستدعاءات (Call Stack)     |  - شجرة المستند (DOM)                      |
|  - ذاكرة الكومة (Memory Heap)        |  - واجهة طلبات الشبكة (Fetch API)          |
|  - أنواع البيانات الأساسية           |  - المؤقتات (setTimeout, setInterval)      |
|  - جامع المهملات (Garbage Collector) |  - التخزين المحلي (localStorage, IndexedDB)|
+--------------------------------------+--------------------------------------------+
                                       |
                                       v
         تُتاح جميعها لأكواد جافا سكريبت عبر الكائن العام `window`
```

> [!NOTE]
> أُضيف المعيار `globalThis` في معيار ES2020 كطريقة قياسية موحدة للوصول إلى الكائن العام في أي بيئة تشغيل (`window` في المتصفح، `global` في Node.js، و `self` في Web Workers).

## 🪟 3. الكائن العام `window`

في بيئة المتصفح، يؤدي كائن `window` دورين أساسيين:
1. **سياق التنفيذ العام (Global Context):** أي متغير غير معلن أو مصرح به بـ `var` يرتبط تلقائياً به.
2. **واجهة التحكم في نافذة أو لسان المتصفح:** يوفر أبعاد الشاشة ومعالجات الأحداث والتحكم في الصفحة.

```javascript
// قياس أبعاد مساحة العرض الفعلية في لسان المتصفح:
console.log(`عرض الشاشة: ${window.innerWidth}px, ارتفاعها: ${window.innerHeight}px`);

// التمرير البرمجي الانسيابي لأعلى الصفحة:
window.scrollTo({ top: 0, behavior: 'smooth' });
```

## 🧭 4. نموذج كائن المتصفح (Browser Object Model - BOM)

يمثل نموذج الـ BOM مجموعة الكائنات التي يوفرها المتصفح للتعامل مع كل ما يقع خارج صفحة الـ HTML نفسها.

```
                  +-------------------+
                  |      window       |
                  +---------+---------+
        +-------------------+-------------------+
        |                   |                   |
+-------v-------+   +-------v-------+   +-------v-------+
|   navigator   |   |   location    |   |    history    |
+---------------+   +---------------+   +---------------+
```

### أ) الكائن `window.location`: الروابط والتنقل
يعرض تفاصيل رابط الصفحة الحالية ويتيح التنقل البرمجي بين الصفحات:
```javascript
// خصائص الرابط: https://example.com:8080/shop/items?category=shoes#reviews
console.log(window.location.protocol); // 'https:'
console.log(window.location.hostname); // 'example.com'
console.log(window.location.port);     // '8080'
console.log(window.location.pathname); // '/shop/items'
console.log(window.location.search);   // '?category=shoes'
console.log(window.location.hash);     // '#reviews'

// دوال التنقل البرمجي:
// 1. assign: الانتقال لصفحة جديدة مع تسجيلها في سجل المتصفح (History):
// window.location.assign('https://example.com/checkout');

// 2. replace: استبدال الصفحة الحالية في السجل (لا يمكن للمستخدم الرجوع بـ Back):
// window.location.replace('https://example.com/login');

// 3. reload: إعادة تحميل الصفحة الحالية:
// window.location.reload();
```

### ب) الكائن `window.history`: سجل تصفح الجلسة
يتيح التحرك للأمام والخلف عبر تاريخ التصفح في اللسان الحالي:
```javascript
window.history.back();    // مكافئ تماماً للنقر على زر الرجوع في المتصفح
window.history.forward(); // مكافئ للنقر على زر التقدم للأمام
window.history.go(-2);    // الرجوع صفحتين إلى الوراء
```
*(في تطبيقات الصفحة الواحدة SPA، تتيح الدالة `history.pushState()` تحديث الرابط دون إعادة تحميل الصفحة).*

### ج) الكائن `window.navigator`: بيانات جهاز ومتصفح العميل
يوفر معلومات حول نظام ومنصة تشغيل العميل:
```javascript
console.log(navigator.language);  // لغة المتصفح: مثل 'ar-EG' أو 'en-US'
console.log(navigator.onLine);    // true إذا كان متصلاً بالإنترنت، و false إذا انقطع الاتصال
console.log(navigator.cookieEnabled); // هل يقبل المتصفح ملفات تعريف الارتباط
console.log(navigator.hardwareConcurrency); // عدد أنوية المعالج (CPU Cores) المتاحة
```

### د) الكائن `window.screen`: أبعاد الشاشة الفيزيائية
يوفر أبعاد ومواصفات شاشة العرض الحقيقية للمستخدم:
```javascript
console.log(`دقة الشاشة: ${window.screen.width} x ${window.screen.height}`);
console.log(`الارتفاع المتاح بدون شريط مهام النظام: ${window.screen.availHeight}`);
```

## 🚫 5. مربعات الحوار المعطلة للواجهة (`alert`, `confirm`, `prompt`)

تحتوي جافا سكريبت على ثلاث دوال قديمة لعرض مربعات حوار منبثقة:
```javascript
alert('تمت العملية بنجاح');
const isConfirmed = confirm('هل أنت متأكد من حذف هذا السجل؟');
const userName = prompt('يرجى إدخال اسمك:');
```

### لماذا تحظرها الشركات والتطبيقات الاحترافية الحديثة؟
1. **تجميد خيط المعالجة (Thread Blocking):** تعطل هذه الصناديق خيط المعالجة الوحيد في المتصفح بالكامل؛ تتوقف كل الحركات وتتجمد المؤقتات وتتعطل التفاعلات في الصفحة حتى يغلق المستخدم الصندوق.
2. **تجربة مستخدم سيئة:** لا يمكن تغيير مظهرها أو تنسيقها بألوان وهوية الموقع (CSS).
3. **مخاطر الخداع والاحتيال:** استخدمتها المواقع الاحتيالية قديماً لخداع المستخدمين وإيهامهم بوجود رسائل نظام وهمية.
*(تعتمد المواقع الحديثة على نوافذ منبثقة مخصصة بـ HTML/CSS أو عنصر `<dialog>` القياسي).*

## 🧼 6. مقارنة الكود النظيف: فحص الميزات مقابل فحص المتصفح

```javascript
// ❌ كود سيئ وهش: محاولة معرفة نوع المتصفح بقراءة نص User-Agent (يسهل تزييفه ويتغير دائماً)
if (navigator.userAgent.includes('Chrome')) {
  // افتراض وجود ميزة معينة بناءً على اسم المتصفح!
  window.customFunction();
}

// ✅ كود ممتاز: فحص الميزة مباشرة (Feature Detection) - التأكد هل الميزة مدعومة برمجياً
if ('geolocation' in navigator) {
  navigator.geolocation.getCurrentPosition(successHandler, errorHandler);
} else {
  console.warn('خدمة تحديد المواقع الجغرافية غير مدعومة في هذا المتصفح.');
}

// ✅ كود ممتاز: التأكد من دعم واجهات الويب الحديثة قبل استدعائها
if (window.structuredClone) {
  const clone = structuredClone(state);
} else {
  // بديل احتياطي للمتصفحات القديمة
  const clone = JSON.parse(JSON.stringify(state));
}
```

## 📝 7. الخلاصة والدرس التالي
- **محرك جافا سكريبت** ينفذ الكود؛ بينما **واجهات المتصفح (Web APIs)** توفر الوصول للشبكة والمستند والشاشة.
- الكائن **`window`** هو الحاوي العام في المتصفحات (و `globalThis` هو المعيار الشامل).
- استخدم **`window.location`** للتعامل مع الروابط؛ وفضّل **`location.replace()`** لإعادة التوجيه الذي يمنع المستخدم من الرجوع لصفحة خاطئة.
- اعتمد دائماً على **فحص الميزات (Feature Detection)** بدلاً من فحص نصوص `navigator.userAgent`.
- في الدرس التالي، سنصل إلى جوهر تطوير الويب: **شجرة عناصر الصفحة والتحكم بها (DOM Manipulation)**.
