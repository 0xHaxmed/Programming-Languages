# 03 - الكائنات والمراجع في الذاكرة وميكانيكا النسخ (Objects, References & Memory)

> 🌐 **Language / اللغة:** [English 🇬🇧](../en/03-objects-and-references.md) | [العربية 🇸🇦](./03-objects-and-references.md)

---

## 🎯 1. نظرة عامة وأهداف التعلم (Overview & Learning Objectives)

في لغة جافا سكريبت، يشكل فهم كيفية تخزين البيانات في الذاكرة الفارق الجوهري بين المطور المبتدئ والمهندس المحترف. بينما تتصرف الأنواع البدائية (Primitives) بشكل متوقع، تعمل الكائنات (بما فيها المصفوفات والدوال) عبر **مراجع الذاكرة (Memory References)**.

بنهاية هذا الدرس، ستتقن:
1. الفرق المعماري بين ذاكرة المكدس (**Stack**) وذاكرة الكومة (**Heap**).
2. كيف تختلف **القيم البدائية (بالقيمة - By Value)** عن **أنواع المراجع (بالمرجع - By Reference)**.
3. مخاطر مشاركة المراجع والتعديلات غير المقصودة على الكائنات (Side Effects).
4. آليات وحدود **النسخ السطحي (Shallow Copy)** باستخدام `...` و `Object.assign`.
5. تنفيذ **النسخ العميق (Deep Copy)** الاحترافي باستخدام واجهة `structuredClone()` الحديثة.
6. حماية الكائنات وتجميدها باستخدام `Object.freeze()` و `Object.seal()`.

## 🧠 2. المكدس مقابل الكومة (Stack vs Heap): كيف تُحجز الذاكرة؟

تقسم بيئات تشغيل جافا سكريبت ذاكرة الوصول العشوائي (RAM) إلى منطقتين رئيسيتين:

```
+------------------------------------+      +-----------------------------------------+
|        CALL STACK (سريع، ثابت)     |      |         MEMORY HEAP (ديناميكي، ضخم)     |
+------------------------------------+      +-----------------------------------------+
| قيمة بدائية: score = 100           |      |                                         |
| قيمة بدائية: isActive = true       |      | بيانات الكائن الفعلية:                  |
| مؤشر مرجعي:  userRef ==============> ===> | { id: 1, name: 'سارة', role: 'Dev' }    |
+------------------------------------+      +-----------------------------------------+
```

### أ) الأنواع البدائية (تُنسخ بالقيمة - By Value)
الأنواع البدائية (`string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`) تُخزن مباشرة داخل الـ Stack. نسخ أي قيمة بدائية ينشئ نسخة مستقلة تماماً:
```javascript
let a = 10;
let b = a; // تم نسخ القيمة 10 في مكان جديد
b = 20;

console.log(a); // 10 (لم تتأثر على الإطلاق!)
console.log(b); // 20
```

### ب) أنواع المراجع (تُنسخ بالمؤشر المرجعي - By Reference)
الكائنات والمصفوفات والدوال تُحجز داخل الـ Heap. المتغير المخزن في الـ Stack لا يحمل الكائن نفسه، بل يحمل **عنوان الذاكرة (Pointer / Reference)** فقط:
```javascript
const userA = { name: 'سارة', age: 25 };
const userB = userA; // تم نسخ عنوان الذاكرة فقط، وليس الكائن!

userB.age = 30; // تعديل الكائن المشترك داخل الـ Heap

console.log(userA.age); // 30! المتغيران يشيران لنفس الكائن تماماً في الذاكرة!
```

## ⚖️ 3. مقارنة الكائنات والتحقق من التطابق

نظراً لأن متغيرات الكائنات تخزن عناوين الذاكرة، فإن معامل التطابق التام (`===`) يقارن **العناوين المرجعية، وليس محتويات الكائن**:

```javascript
const obj1 = { role: 'admin' };
const obj2 = { role: 'admin' };
const obj3 = obj1;

console.log(obj1 === obj2); // false (كائنان مختلفان في عنوانين مستقلين داخل الـ Heap!)
console.log(obj1 === obj3); // true  (يشيران إلى نفس العنوان في الذاكرة بالضبط)
```

## 🧬 4. النسخ السطحي مقابل النسخ العميق (Shallow vs Deep Copy)

عند تكرار الكائنات وتكرارها، يجب التمييز بدقة بين نسخ الخصائص السطحية ونسخ الكائنات المتداخلة.

### أ) النسخ السطحي (Shallow Copy)
التقنيات المستخدمة:
1. معامل النشر: `const copy = { ...original };`
2. دالة التعيين: `const copy = Object.assign({}, original);`
3. اقتطاع المصفوفات: `const copy = originalArray.slice();`

```javascript
const team = {
  name: 'DevSec',
  leader: { name: 'فاطمة', age: 32 } // كائن متداخل!
};

const shallowClone = { ...team };
shallowClone.name = 'RedTeam'; // آمن: الخاصية البدائية name تم نسخها بشكل مستقل

// خطر: الكائنات المتداخلة ما زالت مراجع مشتركة في الذاكرة!
shallowClone.leader.age = 35;
console.log(team.leader.age); // 35! تم تعديل عمر قائد الفريق في الكائن الأصلي أيضاً!
```

### ب) النسخ العميق (Deep Copy)
النسخ العميق ينسخ كل كائن ومصفوفة متداخلة بشكل عودي بحيث تصبح النسخة الجديدة مستقلة بنسبة 100%.

#### الطريقة القياسية الحديثة: `structuredClone()`
مدعومة محلياً في جميع المتصفحات الحديثة و Node.js (إصدار 17 فما فوق):
```javascript
const deepClone = structuredClone(team);

deepClone.leader.age = 40;
console.log(team.leader.age); // 35 (الكائن الأصلي محمي وآمن تماماً!)
```
تتعامل دالة `structuredClone()` بنجاح تام مع المراجع الدائرية (Circular References) وكائنات `Date` و `Set` و `Map`.

#### الطريقة البديلة القديمة: `JSON.parse(JSON.stringify(obj))`
```javascript
const deepClone = JSON.parse(JSON.stringify(team));
```
> [!WARNING]
> **عيوب تحويل JSON:**
> - تحذف الدوال وخصائص `undefined`.
> - تحول كائنات التواريخ `Date` إلى نصوص مجردة.
> - تنهار برمجياً عند وجود مراجع دائرية (`obj.self = obj`).

## 🔒 5. تجميد وتأمين الكائنات: `freeze` مقابل `seal`

توفر جافا سكريبت آليات مدمجة لتقييد التعديل على الكائنات:

### `Object.freeze(obj)`: التجميد الكامل
يمنع إضافة خصائص جديدة، أو حذف خصائص قائمة، أو تعديل قيم الخصائص الموجودة:
```javascript
const config = Object.freeze({
  apiUrl: 'https://api.example.com',
  timeout: 5000
});

// config.timeout = 10000; // يفشل بصمت في الوضع العادي، ويرمي TypeError في 'use strict'
console.log(config.timeout); // 5000
```
*(تنبيه: التجميد سطحي فقط Shallow Freeze. الكائنات المتداخلة تظل قابلة للتعديل ما لم تجمدها عودياً).*

### `Object.seal(obj)`: الإغلاق المحكم
يمنع إضافة أو حذف الخصائص، ولكنه **يسمح بتعديل قيم الخصائص القائمة بالفعل**.

## 🧼 6. مقارنة الكود النظيف (Clean Code: Good vs Bad)

```javascript
// ❌ كود سيئ: تعديل مباشر للكائن الممرر للدالة (ينتج عنه آثار جانبية خطيرة Side Effects)
function activateUser(user) {
  user.isActive = true; // يعدل بيانات المستدعي في الذاكرة مباشرة
  user.lastLogin = new Date();
  return user;
}

// ✅ كود ممتاز: إرجاع نسخة جديدة ومحدثة بشكل غير متلف (Immutable)
function activateUser(user) {
  return {
    ...user,
    isActive: true,
    lastLogin: new Date()
  };
}

// ❌ كود سيئ: استخدام تحويل JSON لنسخ كائنات معقدة تحتوي على تواريخ أو أساليب خاصة
const clone = JSON.parse(JSON.stringify(complexData));

// ✅ كود ممتاز: استخدام الدالة القياسية المعتمدة structuredClone
const clone = structuredClone(complexData);
```

## 📝 7. الخلاصة والدرس التالي
- **القيم البدائية** تُنسخ بالقيمة؛ بينما **الكائنات** تُنسخ بمؤشر عنوان الذاكرة.
- المقارنة بـ `===` بين كائنين تفحص هل يتشاركان نفس العنوان في الـ Heap.
- استخدم **معامل النشر (`...`)** للنسخ السطحي ذي المستوى الواحد.
- استخدم **`structuredClone()`** للنسخ العميق لكافة الكائنات المتداخلة.
- في الدرس التالي، سنغوص في **دوال رد النداء وتمرير الدوال والمعالجة اللاتزامنية الأولية (Callbacks & Foundational Concurrency)**.
