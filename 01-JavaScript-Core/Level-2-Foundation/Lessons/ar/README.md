## 📑 قائمة الدروس المقررة للمستوى الثاني

| الدرس | الملف | المحاور الرئيسية |
| :---: | :--- | :--- |
| **01** | `01-functions-and-data.md` | الدوال السهمية، دوال المصفوفات (`map`, `filter`, `reduce`)، والتفكيك (Destructuring) و Spread/Rest. |
| **02** | `02-scope-and-hoisting.md` | النطاقات (Global, Function, Block) وكيف تعمل آلية الرفع (Hoisting). |
| **03** | `03-objects-and-references.md` | الكائنات المتداخلة، التمرير بالمرجع في الذاكرة، ونسخ الكائنات (Shallow vs Deep Copy). |
| **04** | `04-callbacks.md` | دوال رد النداء (Callbacks) وآلية تمرير الوظائف للتعامل مع الأحداث. |
| **05** | `05-browser-environment.md` | كائنات `window` و `document`، وفهم الحد الفاصل بين محرك JS و Web APIs. |
| **06** | `06-dom-manipulation.md` | شجرة الـ DOM، تحديد العناصر، وإنشاء وحذف وتعديل النصوص والسمات والأنماط. |
| **07** | `07-events-system.md` | الاستماع للأحداث (Event Listeners)، وظاهرة الـ Bubbling والـ Capturing وتفويض الأحداث (Delegation). |
| **08** | `08-forms-and-validation.md` | قراءة الحقول، أحداث `submit` و `input`، والتحقق من صحة المدخلات قبل الإرسال. |
| **09** | `09-urls-and-navigation.md` | التعامل مع الروابط عبر `location`، وتحليل المعاملات باستخدام `URLSearchParams`. |
| **10** | `10-json.md` | تبادل البيانات: تحويل الكائنات إلى JSON والعكس مع معالجة الأخطاء. |
| **11** | `11-network-requests.md` | طلبات الشبكة عبر `fetch()`، التعامل مع الـ Headers، والتحكم في حالات الردود (Status Codes). |
| **12** | `12-async-basics.md` | أساسيات الوعود (Promises)، وحالاتها، واستخدام `async/await` لكتابة كود متزامن الشكل. |
| **13** | `13-browser-storage.md` | التخزين الدائم والمؤقت (`localStorage`, `sessionStorage`)، ومقدمة عن ملفات الـ Cookies. |
| **14** | `14-devtools-debugging.md` | استخدام تبويب Sources، ونقاط التوقف (Breakpoints)، وتتبع الشبكة في تبويب Network. |
| **15** | `15-browser-security-basics.md` | سياسة نفس المصدر (Same-Origin Policy)، الـ CORS، والفرق بين أمان العميل والسيرفر. |
