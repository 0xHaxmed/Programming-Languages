## 📑 Level 2 Lesson Directory

| Lesson | Target File | Core Syllabus Topics |
| :---: | :--- | :--- |
| **01** | `01-functions-and-data.md` | Arrow functions, functional array iterators (`map`, `filter`, `reduce`), destructuring, and spread/rest operators. |
| **02** | `02-scope-and-hoisting.md` | Global, function, and block scope boundaries, and execution context hoisting mechanics. |
| **03** | `03-objects-and-references.md` | Nested object trees, heap memory pointers, shallow vs deep cloning. |
| **04** | `04-callbacks.md` | Passing functions as arguments, callback patterns, and foundational concurrency. |
| **05** | `05-browser-environment.md` | The `window` global and `document` node; delineating JS engine vs Web APIs. |
| **06** | `06-dom-manipulation.md` | The DOM tree structure, query selectors, element creation, dynamic styling, and deletion. |
| **07** | `07-events-system.md` | Event listeners, event lifecycle (capturing & bubbling phases), and event delegation patterns. |
| **08** | `08-forms-and-validation.md` | Form submission trapping (`preventDefault`), input state tracking, and sanitization validation. |
| **09** | `09-urls-and-navigation.md` | Programmatic navigation via `window.location`, and query string parsing via `URLSearchParams`. |
| **10** | `10-json.md` | Serialization/deserialization mechanics with `JSON.stringify` and `JSON.parse`. |
| **11** | `11-network-requests.md` | Network dispatching with `fetch()`, HTTP verbs, headers, status codes, and payload decoding. |
| **12** | `12-async-basics.md` | Asynchronous programming fundamentals: Promise states, chaining, and `async/await` syntax. |
| **13** | `13-browser-storage.md` | Client-side persistence: `localStorage`, `sessionStorage`, and Cookie primitives. |
| **14** | `14-devtools-debugging.md` | Advanced DevTools inspection: Sources panel breakpoints, call stack analysis, and Network tab forensics. |
| **15** | `15-browser-security-basics.md` | The Same-Origin Policy (SOP), Cross-Origin Resource Sharing (CORS), and trust boundaries. |
